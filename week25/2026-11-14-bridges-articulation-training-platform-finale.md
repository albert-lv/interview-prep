## 一、今日算法题：查找集群中的关键连接（LC 1192）

### 题目

`n` 台服务器编号 `0..n-1`，`connections[i] = [a, b]` 表示 a 和 b 之间有一条直连链路。一条「关键连接」是指：**删除它之后，网络被分裂成至少两个不连通部分**的边。返回所有关键连接。

```
输入：n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]
输出：[[1,3]]
解释：0-1-2 构成环，断任意一条都能绕行；只有 1-3 是唯一的通道，断了 3 就孤岛了。
```

### 工程读法（为什么收官选这道题）

Week 25 最后一天的设计题要求一套「可审计、可熔断、可复用」的训练平台。**「可审计」三个字翻成图论就是一句话：先把系统的依赖图画出来，跑一遍 Tarjan，找出所有的桥和割点。**

- **桥（bridge）= 删一条边图就不连通的边**。万卡联邦训练平台里：跨区域的唯一一条专线、权重分发树里某个区域唯一的父种子、checkpoint 到对象存储的唯一一条上传链路——它们每一条都是桥。
- **割点（articulation point）= 删一个节点图就不连通的顶点**。单点 trainer、单实例 reward server、唯一一台任务数据库、以及——**黄仁勋之于英伟达**。33 年单一 CEO、深度绑定的客户关系与供应链谈判、连白宫游说都系于一人：这是把「关键人」三个字写进了图的连通性里。11/12 的公告就是一次现场摘除割点，图抖了一下但没碎（CFO 即刻接任临时 CEO + 首任董事长 + 内外并选的正式遴选 = 摘除割点前先把邻接边接好），代价是 4500 亿美元——**这就是割点的市场价格**。
- **找桥/割点的算法不是奢侈品，是审计清单**。面试里说「我们平台做了高可用」是形容词；说「我对依赖图跑了 Tarjan，还剩 2 个割点、5 条桥，分别在 X 和 Y，Q2 排期双活」是工程。
- 反向口诀也值钱：**想让系统没有单点，就让它双连通（biconnected）**——任意删一台服务器、断一条链路，图依然连通。英伟达董事会 11/12 的操作就是一次双连通化手术。

### 思路：Tarjan low-link（一次 DFS 全搞定）

无向图里 DFS 生成树把边分成两类：
- **树边**：DFS 走过的边，构成一棵生成树；
- **回边（back edge）**：指向祖先的非树边——**它是环的证据，也是绕行的通道**。

对节点 `u` 维护两个时间戳：
- `disc[u]`：DFS 首次访问 u 的序号（发现时间，只增不减）；
- `low[u]`：从 u 出发、经过**任意多条树边 + 至多一条回边**能到达的最小 disc 值。

`low[u]` 的语义：**u 的子树里有没有一条「后门」能绕回祖先**。有后门 = 这条树边不是必经之路；没有后门 = 这条边是桥、这个点是割点。

**判定两条铁律（无向图、不含重边时）：**

```
low[v] >  disc[u]   ⟺  树边 (u,v) 是桥
                      （v 的整个子树没有任何回边能碰到 u 或 u 的祖先——v 只能经过 u 进出）

low[v] >= disc[u]   ⟺  u 是割点（v 是 u 的子树中满足此条件的儿子）
                      （等于也成立：回边最多只能摸到 u 自己，删了 u 子树照样断）
```

根节点是例外：**根是割点 ⟺ 它有两个以上独立的 DFS 儿子**（它的儿子之间无法互相绕行，因为没有父边可删）。

```go
var (
    disc []int
    low  []int
    timer int
    res  [][]int
    adj  [][]int
)

func criticalConnections(n int, connections [][]int) [][]int {
    adj = make([][]int, n)
    for _, c := range connections {
        a, b := c[0], c[1]
        adj[a] = append(adj[a], b)
        adj[b] = append(adj[b], a)
    }
    disc = make([]int, n)
    low = make([]int, n)
    for i := range disc { disc[i] = -1 } // -1 = 未访问
    res = nil
    timer = 0
    for i := 0; i < n; i++ {
        if disc[i] == -1 {
            dfs(i, -1)
        }
    }
    return res
}

func dfs(u, parent int) {
    disc[u] = timer
    low[u] = timer
    timer++
    childCount := 0
    for _, v := range adj[u] {
        if v == parent {
            continue // 无向图中直接跳过父节点（含重边时需用边 id 判断，见坑 ①）
        }
        if disc[v] == -1 {
            // 树边：先递归，再用子树的 low 回传
            childCount++
            dfs(v, u)
            low[u] = min(low[u], low[v])
            if low[v] > disc[u] {
                res = append(res, []int{u, v}) // (u,v) 是桥
            }
            // 割点判定（本题只问桥，面试必追问）：
            // if parent != -1 && low[v] >= disc[u] { u 是割点 }
        } else {
            // 回边：v 是已访问祖先（或横叉边，无向图里横叉边必已被访问）
            low[u] = min(low[u], disc[v])
        }
    }
    // if parent == -1 && childCount >= 2 { 根是割点 }
}
```

### 复杂度

- **时间 O(V + E)**：每个节点访问一次，每条边看两次（无向图）——比「逐条边删了再 BFS 验连通」的 O(E·(V+E)) 快了 E 倍；
- **空间 O(V + E)**：邻接表 + 两个时间戳数组 + DFS 栈。

### 面试三坑

1. **`v == parent` 直接跳过在重边场景会漏判**。如果 a、b 之间有两条并行链路（万卡集群里双网卡 bonding 就是物理重边），删一条还有一条，不该报桥。正确做法：DFS 传**边 id** 而不是父节点值，`if edgeID == parentEdge { continue }`——两条不同 id 的平行边都能走到对方，环成立，无桥。**工程语境下「双链路冗余」就是人工制造重边，让它天然不是桥。**
2. **回边用 `disc[v]` 而不是 `low[v]`**。`low[v]` 是从 v 走后门能到的最早点，用它会把「v 子树的后门」错记成「u 的后门」，判定条件整体前移，桥会被漏报。一句记：树边看儿子的 low，回边看对方的 disc。
3. **非连通图要外层循环**。集群按 region 隔离时依赖图天然非连通——每个连通分量各跑一次 DFS， timer 不用重置（时间戳全局单调不影响正确性，只影响可读性）。

### 进阶六连

1. **点双连通分量（BCC）分解**：割点是多个 BCC 的公共点。工程对应：把一个超大训练平台拆成「任意内部无割点」的故障域单元，单元之间用冗余连接——**双连通化的施工图**。
2. **边双连通分量 + 加边使图无桥**：最少加几条边让全图没有桥？= 把边双连通分量缩点后得到一棵树，树的叶子两两配对 ⌈叶子数/2⌉——「加冗余链路预算」的标准答案。Anthropic 对 Azure+GCP 双承诺（449 亿+1145 亿）就是付钱消桥。
3. **在线维护桥（动态图）**：边只加不删可用并查集+Tarjan 离线；完全动态是难题——面试答「工程上用定期重跑 Tarjan 审计 + 变更触发增量检查」即满分。
4. **桥与强连通的混搭**：有向图找「缩点后入度为 0 的 SCC」（连通分量数 -1 条边即可全连通）——**任务依赖 DAG 补几条依赖边才能让全图可调度**。
5. **最小割 vs 桥**：桥是「删一条边」，最小割是「删最少边使 s、t 不连通」——万卡联邦「攻击者最少炸几条链路能切断 trainer 与某 region rollout worker」的对抗模型，max-flow min-cut 一把梭。
6. **本题换皮**：LC 1489 找到最小生成树里的关键边和伪关键边——「MST 里哪些边是不可替代的」= 成本图上的桥，和 Day 162 的性价比选型连起来看。

### 工程映射：万卡联邦训练平台的 Tarjan 审计清单

把平台依赖图画出来：节点 = trainer / rollout pool / reward service / checkpoint store / 任务 DB / 网关 / 各 region；边 = 数据流与控制流。跑一遍 Tarjan，输出三类报告：

- **桥报告**：「Region B 与全局权重分发树之间只有一条父链路」→ 修法 = P2P swarming 多父（Day 160），把树改成网状，桥变重边；
- **割点报告**：「reward service 单实例」→ 修法 = 无状态水平扩 + 持久队列（Day 161）；「任务 DB 单写」→ 修法 = 分片 + 选主；
- **重边体检**：「名义 100 节点的 spot 池实际共享 3 个独立故障单元」（Day 162 相关性警告）= 缩点后数连通分量的补问题。

**一句话：可审计 = 图上的桥和割点有名字、有数量、有排期。**

### 3. 混合模拟面试：万卡联邦 Agentic RL 训练平台

> **题目：从单集群（256 卡）到万卡联邦（多 region、多供应商、spot 为主），设计一套可审计、可熔断、可复用的 Agentic RL 训练平台。**

**开场（30 秒定调）**：先定义三个词——**可审计 = 每个 token 的 reward 可归因、每次熔断可复盘（图上有名字的桥和割点）；可熔断 = 预算/质量/一致性三个维度各有三旋钮，不是一个 panic 按钮；可复用 = rollout 资产（episode 片段、任务、judge 缓存）跨 run 跨集群流通。**

**四步答法：**

**① 三澄清**：联邦的边界是什么（跨 region 还是跨供应商）？允许的数据流动（轨迹/权重出不出域）？SLA 分层（哪些任务可牺牲、哪些必须 on-demand 保）？——与 Day 162 成本澄清同构，只是维度换成「地域与合规」。

**② 架构分层（每层假设上一层已失效）**：
- **任务与调度层**：全局调度器按就绪度组 batch（TideRL 思想）；任务带优先级与配额标签（Day 162 配额制）；
- **rollout 层**：无状态 worker + sandbox 池，spot 为主、无状态化为准入门槛（RLinf 模式）；episode 片段进 APRIL buffer 跨集群复用；
- **权重分发层**：CDN 式三层分发 + P2P swarming，版本号 + Merkle 根先校验后切换，P90 水位线以上才放行下一步（Day 160 全搬）；
- **reward 层**：分层 + 缓存 + least-in-flight + degraded 标记（Day 161 全搬）；
- **状态层**：checkpoint 分层保留（最近 N + 里程碑 + 审计点），λ×W 动态定频（Day 154/162）。

**③ 联邦特有机制（加分项）**：
- **故障域审计 = 今天这道 Tarjan**：对全局依赖图定期跑桥/割点检测——跨 region 单链路、单 region 的 seed、单供应商的 spot 池都是桥/割点候选；产出报告并绑定整改排期。**面试金句：「高可用不是形容词，是 Tarjan 的输出。」**
- **相关性管理**：多供应商 × 多 AZ × 多机型打散，独立故障单元数 ≥ 目标副本数（Day 162：名义 100 节点实际可能只有 3 个独立单元）；
- **权重与数据的合规边界**：出域数据走脱敏轨迹 + 聚合梯度，权重分发按区域白名单——把「地域」写进版本协议的属性里。

**④ 治理与兜底**：预算熔断三旋钮（排队/涨价/配额，Day 162 Anthropic 三板斧）+ 质量熔断（gap 曲线张开 → 冻结 checkpoint → 修 reward）+ 一致性熔断（P90 水位线不达标 → 暂停 commit）；**所有熔断动作进审计日志，报警链路独立部署**（两条铁律，防自举失败）。

**⑤ 时事点睛（收尾必带）**：黄仁勋辞职证明——**系统的连通性不能依赖任何单点，包括人和公司**：英伟达 33 年把 CEO 活成了割点，摘除瞬间市值蒸发 4500 亿美元；而董事会「临时 CEO 即刻就位 + 首任董事长 + 内外并选」三步走，是标准的「摘除割点前先接好边」。Anthropic 敢在 11/18 定价、赌 IPO 前夜行业不失联——**万卡联邦的第一课就是：把黄仁勋测试写进你的混沌剧本，任何组件、任何人被摘除，图都得还连着。**

### 4. 模拟面试速答五连

- **Q1 万卡联邦第一优先级是什么？** 不是扩容，是**故障域审计**：先跑 Tarjan 找桥/割点，再谈调度。没有审计的扩容 = 把单点复制一万份。
- **Q2 spot 池抢占率全线上涨怎么办？** 重算真实成本 = 名义价 ÷ (1 − p)（Day 162）；关键路径迁回 on-demand；池子跨供应商重平衡防相关性；抢占窗口前主动 checkpoint = 优雅让位比被杀死便宜。
- **Q3 怎么向老板证明 reward 没被 hack？** 三证据：train/eval gap 曲线（仪表盘）、输出分布漂移（体温计）、canary 任务集 + 人工审计（活检）。**只说「benchmark 涨了」等于什么都没说。**
- **Q4 区域间网络中断，训练怎么办？** 桥已提前消掉（多路径 + P2P）；按区域自治降级：本地 rollout 照常、权重更新异步追赶、全局 commit 等水位线；**保每个 region 的 episode 产能，牺牲全局同步新鲜度**——训练连续性 > 强一致。
- **Q5 这套平台最大的隐性成本是什么？** 人力与认知成本：分布式故障的 debug 按周计；可观测性、确定性复现、版本协议全是省人钱的手段——**集群租金经常不是账单的大头，人才是。**

### 5. 今日金句

> **黄仁勋辞职给全世界上了一堂价值 4500 亿美元的图论课：一个系统最大的单点故障，往往是那个你最不愿意写成割点的节点——可以是人、可以是唯一的 trainer、也可以是唯一的排序键。可审计的全部要义，就是先把依赖图画出来，让每一条桥和每一个割点都有名字、有价格、有摘除预案；可复用的全部要义，是让资产（episode、缓存、checkpoint）在故障发生时仍然流动；而可熔断的全部要义，是承认容量永远不够，然后像 Anthropic 的承销商一样——涨价是传导，绿鞋是扩容，优先分配是配额。高可用不是形容词，是 Tarjan 的输出。**

### 6. 收官自检清单（10 项）
