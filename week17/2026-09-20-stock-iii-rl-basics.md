## 1) 今日算法题

### 买卖股票的最佳时机 III（Best Time to Buy and Sell Stock III）

**题意**：给定数组 `prices`，第 `i` 天价格为 `prices[i]`。你**最多完成两笔交易**（一笔 = 一次买 + 一次卖，同一时刻最多持有一股，必须先卖后才能再买），求最大利润。

```
输入: prices = [3,3,5,0,0,3,1,4]
输出: 6
解释: 第 4 天买(0) 第 6 天卖(3) → +3；第 7 天买(1) 第 8 天卖(4) → +3；总利润 6
```

### 思路：状态机 DP = 离散版 Bellman 方程

把"某天结束时的状态"定义清楚，转移自然浮现：

- 状态 `dp[k][s]`：`s=1` 持股、`s=0` 不持股；`k` = **已经完成的交易笔数**。
- 每天对每个状态只有几个**动作**：买 / 卖 / 观望（观望被 `max` 天然涵盖）。

转移方程（k = 已完成笔数版本）：

```
持股   dp[k][1] = max(dp[k][1],  dp[k][0]   - price)   // 买：不持股状态花 price
不持股 dp[k][0] = max(dp[k][0],  dp[k-1][1] + price)   // 卖：持股状态收 price，笔数从 k-1 升级
```

要点：**买入时 k 不变，卖出时才结算"完成一笔"**（从 `k-1` 的持股态升级）。边界：`dp[*][1] = -∞`（不可能零成本持股）。答案 = `max(dp[0..2][0])`。

手算 `[3,3,5,0,0,3,1,4]`：第 4 天价格 0 买入 → 第 6 天 3 卖出完成第一笔；第 7 天 1 买入 → 第 8 天 4 卖出完成第二笔；累计 6。

**空间压缩**：每天只依赖前一天，滚动数组把 O(n·k) 压到 O(k) —— k=2 时就是 6 个变量，再手写消元就是 4 个。

### 代码

**Go（通用 k 笔模板，本题 k=2 直接调用）：**

```go
func maxProfitK(prices []int, k int) int {
    buy := make([]int, k+1)  // buy[j]: 已完成 j 笔、当前持股 的最大现金
    sell := make([]int, k+1) // sell[j]: 已完成 j 笔、当前不持股 的最大现金
    for j := 0; j <= k; j++ {
        buy[j] = math.MinInt32
    }
    for _, p := range prices {
        for j := 1; j <= k; j++ {
            buy[j] = max(buy[j], sell[j-1]-p) // 买：花 p，已完笔数不变
            sell[j] = max(sell[j], buy[j]+p)  // 卖：收 p，从持股态结算一笔
        }
    }
    return sell[k]
}
```

**Python（k=2 极简四变量版）：**

```python
def maxProfit(prices):
    b1 = b2 = float('-inf')  # 第一/第二笔交易持股时的最大现金
    s1 = s2 = 0              # 第一/第二笔交易不持股时的最大现金
    for p in prices:
        b1 = max(b1, -p)      # 第一次买
        s1 = max(s1, b1 + p)  # 第一次卖
        b2 = max(b2, s1 - p)  # 第二次买（用第一笔的利润）
        s2 = max(s2, b2 + p)  # 第二次卖
    return s2
```

### 复杂度

- **时间**：O(n·k)，k=2 时即 O(n)
- **空间**：O(k)，压缩后 O(1)

> 💡 **Follow-up 三连**：
> - **k 很大**（k ≥ n/2）→ 退化成"无限次交易"贪心：累加所有正差分 `Σ max(0, p[i]-p[i-1])`。
> - **含冷冻期**（卖出后一天不能买）→ 多一个"冷冻"状态，三维状态机。
> - **含手续费** → 在买或卖动作上减 `fee`，方程里加一项而已，骨架不动。
>
> 💡 **今天的隐藏彩蛋**：`dp[状态] = max(原地不动, 各动作带来的新值)` 就是强化学习里的 **Bellman 最优方程**。股票 DP 是"确定性转移 + 模型已知"的 MDP；RL 处理的是"转移概率未知、只能靠采样估计"的同一个方程。记住这个对应，今天的面试技巧会顺得飞起。

## 2) 面试技巧 — 强化学习基础

Week 17 开场：MDP → Bellman → Q-Learning → DQN，一条线讲清楚。

### 🧩 MDP 五要素（开场必背）

| 要素 | 符号 | 股票问题里的对应 |
|---|---|---|
| 状态 State | s | （天数，已用交易次数，是否持股） |
| 动作 Action | a | 买 / 卖 / 观望 |
| 转移概率 | P(s′\|s,a) | 股票里是确定的（下一天必来），一般环境是概率 |
| 奖励 Reward | r | 卖出 +p，买入 −p |
| 折扣因子 | γ | 明天的钱不如今天的钱值钱 |

强化学习 = **在模型 P 未知时，靠交互采样学出最优策略 π\*(a|s)**。这就是它和 DP 的分界线：DP 是开卷考试（P、r 全知道），RL 是闭卷试错。

### 📐 Bellman 方程组（会写这两个式子，RL 就懂了一半）

**期望方程（评估一个策略）：**

```
V^π(s) = Σ_a π(a|s) · Σ_s' P(s'|s,a) · [ r(s,a) + γ · V^π(s') ]
```

**最优方程（直接找最优）：**

```
V*(s)  = max_a  Σ_s' P(s'|s,a) · [ r + γ · V*(s') ]
Q*(s,a) = Σ_s' P(s'|s,a) · [ r + γ · max_a' Q*(s',a') ]
```

看出来了吗？股票 DP 里 `max(原地, 买, 卖)` 就是 `max_a` 的确定性特例。**面试时把这个对应说出口，比背定义高一个档次。**

### 🔁 策略迭代 vs 值迭代

- **策略迭代**：评估当前策略 → 贪心改进 → 再评估……两步循环，精确但每一步都贵。
- **值迭代**：直接对 Bellman 最优方程做不动点迭代 `V ← max_a(...)`，不求策略，值收敛了策略顺手就出来了。更快，是主流。

### 🎯 Q-Learning（off-policy）vs SARSA（on-policy）

```
SARSA:   Q(s,a) ← Q + α [ r + γ·Q(s', a')        - Q ]   // a' 按当前策略真实选出来
Q-Learn: Q(s,a) ← Q + α [ r + γ·max_a' Q(s',a')  - Q ]   // a' 直接取最优，不管实际执行了啥
```

- **on-policy**：评估并改进"我正在执行的策略"（SARSA，保守，跟着自己走）
- **off-policy**：学"最优策略该多好"（Q-Learning，激进，样本效率高，工业界主流）
- 行为策略配 **ε-greedy**：1−ε 选当前最优动作，ε 随机探索 —— 探索与利用的经典折中

### 🕹 DQN：让 Q-Learning 上深度网络

两个致命问题 → 两个工程补丁：

1. **样本相关性强**：连续经验高度相似，神经网络（假设 i.i.d.）直接学崩 → **经验回放 Experience Replay**：存进 replay buffer，训练时随机小批量采样，打散相关性，还能复用历史数据。
2. **目标值抖动**：目标 `r + γ·max Q` 里的 Q 每步都在变，回归任务追着移动靶跑 → **目标网络 Target Network**：online net 照常更新，target net 隔 N 步才拷贝一次参数，让监督目标暂时稳定。

> 🎤 **面试官爱问**："DQN 为什么需要 target network？"
> 一句话：**bootstrapping 时目标值自己也来自模型，等于让监督学习的回归目标追着模型跑，必震荡；目标网络把目标"冻结"一阵，是工程止血带。** 往深了说，这就是"死亡三角 deadly triad"（函数逼近 + bootstrapping + off-policy）的体现。

### 🗺 从 DP 到 DQN 的进化路（一张嘴版）

```
DP（模型已知）  → 值/策略迭代，精确解 Bellman 方程
MC 蒙特卡洛     → 模型未知，整局跑完再回算回报：无偏差、方差大
TD 时序差分     → 走一步就更新（bootstrap）：方差小、引入偏差
SARSA/Q-Learning→ TD 的控制版，学动作价值 Q
DQN             → Q 表换成神经网络 + 回放 + 目标网络，状态可以是像素
```

### 🎤 高频连环问速答

**Q1：强化学习和监督学习本质区别？**
> 监督学习的答案是别人给的（标签）；RL 只有奖励信号，且奖励通常**滞后、稀疏** —— 当前动作的好坏要等很久才体现（credit assignment 难题）。所以 RL 的核心是"试错 + 把延迟的回报分配给当初的每个动作"。

**Q2：on-policy 和 off-policy 区别？各举一例？**
> on-policy 用当前策略采的样本来改进当前策略（SARSA、A2C）；off-policy 可以用旧策略甚至别人的样本来学最优策略（Q-Learning、DQN）。off-policy 样本效率高，是工业界主流。

**Q3：ε-greedy 的 ε 怎么调？**
> 前期大（探索，可从 1.0 线性衰减），后期小（利用，0.01~0.1）。变体：UCB 用置信上界显式权衡探索价值，softmax 策略按 Q 值比例采样。说出"ε 衰减"及格，补一句 UCB 加分。

**Q4：为什么需要折扣因子 γ？**
> ① 数学上保证无穷步回报求和收敛；② 刻画"远期的钱不值钱"；③ γ→0 短视（只看眼前），γ→1 深谋远虑但估计方差大。episodic 任务天然有终止状态截断，γ=1 也常见。

**Q5：DQN 的两个 trick 各解决什么问题？**
> 经验回放解决样本相关性（NN 需要近似独立同分布）；目标网络解决非平稳目标（bootstrap 目标自己也在动）。本质是"RL + 函数逼近 = 死亡三角"的针对性止血。

**Q6：状态空间太大、Q 表存不下怎么办？**
> 函数逼近：线性特征 → 神经网络（DQN）。再进一步，直接参数化策略 π_θ(a|s) 用梯度上升优化（策略梯度），连 Q 都不用显式维护 —— 这就是明天 Day 109 的内容。

### 🧭 和工作场景连接（Agentic RL 视角）

你正在做的 agentic RL 跑在 veRL 这类框架上，本质就是这套理论的工业放大版：agent 状态 = LLM 的 context，动作 = 生成 token / 调用工具，奖励 = reward model 打分或规则校验，γ 常取 1（episode 有限长）。**PPO 里的 value model 估的就是 V(s)** —— 今天 Bellman 方程里的那个 V。别把这些当纯八股，全是你下周代码里要调的东西。
