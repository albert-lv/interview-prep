## 一、今日算法题：完全背包问题

### 题目描述

给定 `n` 种物品，每种物品有一个重量 `weight[i]` 和一个价值 `value[i]`。现有一个容量为 `W` 的背包，**每种物品可以选无限次**（完全背包），问在不超过背包容量的前提下，能获得的最大价值是多少？

**示例**：
- weight = [1, 2, 3], value = [6, 10, 12], W = 5
- 输出：30（选 5 次物品 0，重量 5，价值 30）
- 或：选 2 次物品 1 + 1 次物品 0，重量 5，价值 26... 实际上最优是选物品 0 五次：5×6=30

### 思路分析

**核心思想**：与 0-1 背包的唯一区别——每种物品可以选多次。状态定义相同，但转移时要考虑“选 k 次”的可能性。

**状态定义**：
- `dp[j]`：背包容量为 `j` 时，能获得的最大价值

**状态转移方程**：
- 对于第 `i` 个物品，可以选 0 次、1 次、2 次...直到背包装不下
- `dp[j] = max(dp[j], dp[j - weight[i]] + value[i])`（允许重复选）

**关键区别——遍历顺序**：
- 0-1 背包：容量 **逆序** 遍历（避免重复选）
- 完全背包：容量 **正序** 遍历（允许重复选）

### 代码示例

```python
# 基础版：三维思路（不实用，用于理解）
def complete_knapsack_3d(weights, values, W):
    n = len(weights)
    # dp[i][j]：前 i 种物品，容量 j 的最大价值
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for j in range(W + 1):
            # 选 k 次第 i-1 种物品，k 从 0 开始直到装不下
            k = 0
            while k * weights[i-1] <= j:
                dp[i][j] = max(dp[i][j], 
                               dp[i-1][j - k * weights[i-1]] + k * values[i-1])
                k += 1
    
    return dp[n][W]

# 优化版：一维 DP（正序遍历容量）
def complete_knapsack_1d(weights, values, W):
    n = len(weights)
    dp = [0] * (W + 1)
    
    for i in range(n):
        # 正序遍历！允许同种物品被多次选中
        for j in range(weights[i], W + 1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[W]

# 优化版：先遍历容量再遍历物品（另一种写法）
def complete_knapsack_alt(weights, values, W):
    dp = [0] * (W + 1)
    
    # 先遍历容量，再遍历物品
    for j in range(1, W + 1):
        for i in range(len(weights)):
            if j >= weights[i]:
                dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[W]
```

### 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三维思路（k 循环） | O(n × W²) | O(n × W) |
| 一维 DP（优化版） | O(n × W) | O(W) |

## 二、面试技巧

### 1. 一句话区分 0-1 背包和完全背包

> "0-1 背包是**逆序**遍历容量，每种物品只能选一次；完全背包是**正序**遍历容量，同种物品可以反复选。"

面试时如果能快速说出这个对比，面试官立刻知道你把两类背包问题吃透了。

### 2. 为什么正序遍历就是完全背包？

标准回答：
> "正序遍历时，当处理 `dp[j]` 时，`dp[j - weight[i]]` 可能已经被当前物品 `i` 更新过了。这意味着我们允许『用已更新过的状态再去选一次同样的物品』，即同种物品可以无限次使用。"

画个简单例子：物品重量=2，价值=3，容量=4
- 正序：`dp[2] = 3` → `dp[4] = dp[2] + 3 = 6`（选了两次）✓
- 逆序：`dp[4]` 先算，`dp[4] = max(dp[4], dp[2] + 3)`，但此时 `dp[2]` 还没被更新，所以不会重复选 ✓

### 3. 常见应用场景

完全背包不只是理论问题，很多实际场景都是它：

| 场景 | 转化方式 |
|------|---------|
| 凑零钱（最少硬币数） | 金额=容量，硬币面值=重量，数量=价值，求最小化 |
| 整数拆分 | 数字=容量，拆分出的数=物品 |
| 单词拆分 | 字符串长度=容量，单词长度=物品 |

### 4. 面试追问：如果物品有数量上限呢？

这就是**多重背包**问题。两种转化方式：

1. **二进制拆分**：把 `k` 个物品拆成 1, 2, 4, 8... 个的组合，转化为 0-1 背包
2. **单调队列优化**：O(n × W) 解决，但面试极少要求写

回答思路：
> "如果有数量限制，可以先尝试二进制拆分，把多重背包转化为 0-1 背包。如果数量特别大，可以用单调队列优化到 O(n × W)。"

### 5. 一个经典面试坑

问：如果题目是"恰好装满"，0-1 背包和完全背包的初始化有什么区别？

答：**没有区别**。初始化方式只取决于"是否要求恰好装满"，与背包类型无关：
- 不要求恰好装满：`dp[0...W] = 0`
- 要求恰好装满：`dp[0] = 0`，`dp[1...W] = -inf`（或一个极小值）

## 三、0-1 背包 vs 完全背包 对比总结

| 对比项 | 0-1 背包 | 完全背包 |
|--------|---------|---------|
| 物品数量限制 | 每种 1 个 | 每种无限个 |
| 一维 DP 遍历顺序 | **逆序**（j 从 W 到 weight[i]） | **正序**（j 从 weight[i] 到 W） |
| 状态转移 | `dp[j] = max(dp[j], dp[j-w]+v)` | 形式相同，但遍历顺序不同 |
| 经典题目 | 0-1 背包、分割等和子集 | 凑零钱、整数拆分、单词拆分 |
