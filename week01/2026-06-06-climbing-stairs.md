## 今日算法题：爬楼梯（Climbing Stairs）

### 题目描述
假设你正在爬楼梯，需要 `n` 阶才能到达楼顶。每次你可以爬 1 或 2 个台阶。问有多少种不同的方法可以爬到楼顶？

### 示例
```
输入: n = 3
输出: 3
解释: 1+1+1, 1+2, 2+1
```

### 解题思路

**状态定义**：`dp[i]` 表示爬到第 `i` 阶的方法数

**状态转移**：`dp[i] = dp[i-1] + dp[i-2]`
- 最后一步如果是 1 阶，前面有 `dp[i-1]` 种方法
- 最后一步如果是 2 阶，前面有 `dp[i-2]` 种方法

**初始条件**：`dp[0] = 1, dp[1] = 1`

**代码实现**：
```python
def climbStairs(n: int) -> int:
    if n <= 1:
        return 1
    dp = [0] * (n + 1)
    dp[0], dp[1] = 1, 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

**空间优化**：
```python
def climbStairs(n: int) -> int:
    if n <= 1:
        return 1
    a, b = 1, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

**复杂度**：时间 O(n)，空间 O(1)（优化后）

### 注意点
- 这其实就是斐波那契数列！`dp[i]` = Fib(i+1)
- 面试常考，因为能同时考察递归思维和 DP 思维
- 如果面试官要求 O(log n)，可以用矩阵快速幂，但很少问到

## 面试技巧：如何讲清楚 DP 思路

**1. 先讲暴力解法**
- 递归/回溯：O(2^n)
- 画出递归树，指出重叠子问题
- 这是引出 DP 的"钩子"

**2. 四步走**
1. **定义状态**：`dp[i]` 代表什么？
2. **状态转移**：怎么从已知推未知？
3. **初始条件**：边界情况是什么？
4. **遍历顺序**：按什么顺序填表？

**3. 画图辅助**
- 在纸上画一个小表格
- 手填前几项，让面试官看到规律
- 这能展示你的结构化思维

**4. 优化扩展**
- 空间优化：滚动数组
- 时间优化：矩阵快速幂、单调队列
- 显示你对复杂度敏感
