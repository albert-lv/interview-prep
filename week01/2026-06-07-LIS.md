## 今日算法题：最长递增子序列（LIS）

### 题目描述
给定一个整数数组 `nums`，返回其中最长严格递增子序列的长度。

**子序列**：由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。

### 示例
```
输入: nums = [10, 9, 2, 5, 3, 7, 101, 18]
输出: 4
解释: 最长递增子序列是 [2, 3, 7, 101]，因此长度为 4
```

### 解题思路

**状态定义**：`dp[i]` 表示以第 `i` 个元素结尾的最长递增子序列长度

**状态转移**：
```
dp[i] = max(dp[j] + 1)  for all j < i where nums[j] < nums[i]
```
- 遍历所有在 `i` 之前的元素 `j`
- 如果 `nums[j] < nums[i]`，说明 `nums[i]` 可以接在 `nums[j]` 后面
- 取所有可能中的最大值

**初始条件**：`dp[i] = 1`（每个元素单独构成长度为1的子序列）

**代码实现**：
```python
def lengthOfLIS(nums: list[int]) -> int:
    if not nums:
        return 0
    
    n = len(nums)
    dp = [1] * n  # 初始：每个元素单独构成长度1
    
    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)
```

**进阶：二分优化 O(n log n)**：
```python
import bisect

def lengthOfLIS(nums: list[int]) -> int:
    tails = []  # tails[i] = 长度为i+1的递增子序列的最小末尾元素
    
    for num in nums:
        pos = bisect.bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    
    return len(tails)
```

**复杂度对比**：
| 版本 | 时间 | 空间 |
|---|---|---|
| DP | O(n²) | O(n) |
| 二分优化 | O(n log n) | O(n) |

> 面试时先写 DP 版本，再提优化，展示深度

## 面试技巧：STAR 法则讲项目

**场景**：面试官问"说说你最有挑战的一个项目"

**话术模板**：
```
Situation（背景）：我们团队负责 XX 系统，当时面临 QPS 从 1k 涨到 10k 的压力
Task（任务）：我的任务是保证系统不崩，且延迟 < 200ms
Action（行动）：我做了三件事：1）引入缓存 2）优化数据库索引 3）限流降级
Result（结果）：最终 QPS 10k 时延迟 150ms，系统零故障运行了 6 个月
```

**避坑**：
- ❌ 只说"我负责了后端开发"（太笼统）
- ❌ 用"我们"模糊个人贡献
- ✅ 量化结果（数字说话）
- ✅ 突出你的独特动作，不是团队整体

**练习建议**：
准备 3 个不同难度的项目故事：
1. 简单项目：展示基本能力（1-2分钟）
2. 中等项目：展示解决问题能力（3分钟）
3. 困难项目：展示架构和领导力（5分钟）
