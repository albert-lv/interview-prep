## 一、今日算法题：打家劫舍

### 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。**相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums`，计算你 **不触动警报装置** 的情况下，今晚能够偷窃到的最高金额。

**示例**：
- 输入：`nums = [1, 2, 3, 1]`
- 输出：`4`
- 解释：偷窃第 1 间（金额 1）和第 3 间（金额 3），总金额 = 1 + 3 = 4

**进阶示例**：
- 输入：`nums = [2, 7, 9, 3, 1]`
- 输出：`12`
- 解释：偷窃第 1 间（2）、第 3 间（9）和第 5 间（1），总金额 = 2 + 9 + 1 = 12

### 思路分析

**核心思想**：对于每一间房屋，你只有两个选择——偷还是不偷。如果偷，就不能偷前一间；如果不偷，就等于前一间的最大金额。

**状态定义**：
- `dp[i]`：偷到第 `i` 间房屋时，能获得的最大金额

**状态转移方程**：
```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```
- **不偷第 i 间**：金额 = `dp[i-1]`（继承前一间的最优解）
- **偷第 i 间**：金额 = `dp[i-2] + nums[i]`（不能偷前一间，加上当前金额）

**为什么不是 `dp[i-1] + nums[i]`？**
因为相邻不能同时偷。如果偷第 `i` 间，第 `i-1` 间一定没偷，所以最佳收益只能来自前前间 `dp[i-2]`。

**初始条件**：
- `dp[0] = nums[0]`（只有一间，只能偷它）
- `dp[1] = max(nums[0], nums[1])`（两间选金额大的）

### 代码示例

```python
def rob(nums: list[int]) -> int:
    if not nums:
        return 0
    n = len(nums)
    if n == 1:
        return nums[0]
    
    # dp[i] 表示到第 i 间房屋的最大金额
    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    
    for i in range(2, n):
        dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    
    return dp[n-1]
```

**空间优化版**（滚动数组）：

```python
def rob_optimized(nums: list[int]) -> int:
    if not nums:
        return 0
    n = len(nums)
    if n == 1:
        return nums[0]
    
    # 只保留前两间房屋的状态
    prev2 = nums[0]  # dp[i-2]
    prev1 = max(nums[0], nums[1])  # dp[i-1]
    
    for i in range(2, n):
        curr = max(prev1, prev2 + nums[i])
        prev2 = prev1
        prev1 = curr
    
    return prev1
```

**再压缩一行版**：

```python
def rob_oneliner(nums: list[int]) -> int:
    prev2, prev1 = 0, 0
    for num in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + num)
    return prev1
```

### 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 标准 DP 数组 | O(n) | O(n) |
| 滚动数组优化 | O(n) | O(1) |

## 二、面试技巧

### 1. 如何解释「为什么状态转移方程是 max(dp[i-1], dp[i-2] + nums[i])」？

面试官问这个问题，本质是考察你是否真的理解「选择」的结构。

标准回答框架：
> "对于第 `i` 间房屋，我面临两个互斥的选择：
> 1. **不偷**：那么最大金额就是前 `i-1` 间房屋的最优解 `dp[i-1]`
> 2. **偷**：那么第 `i-1` 间不能偷，最大金额是前 `i-2` 间最优解加上当前金额 `dp[i-2] + nums[i]`
> 两者取最大值，就是 `dp[i]`。"

### 2. 画图辅助（面试现场利器）

拿 `nums = [2, 7, 9, 3, 1]` 举例，在纸上画表格：

| 房屋 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 金额 | 2 | 7 | 9 | 3 | 1 |
| dp   | 2 | 7 | 11| 11| 12|

手填过程：
- `dp[0] = 2`
- `dp[1] = max(2, 7) = 7`
- `dp[2] = max(7, 2+9) = 11`（偷第2间）
- `dp[3] = max(11, 7+3) = 11`（不偷第3间）
- `dp[4] = max(11, 11+1) = 12`（偷第4间）

面试官看到你现场画表格，立刻知道你的思维是结构化的。

### 3. 常见变体：环形房屋（House Robber II）

如果房屋围成一个圈（首尾相邻），怎么办？

**核心思路**：环形 = 首尾的互斥，拆成两个线性问题：
- 情况 A：偷第 1 间 → 不能偷最后一间 → 对 `nums[0:n-1]` 求线性 DP
- 情况 B：不偷第 1 间 → 可以偷最后一间 → 对 `nums[1:n]` 求线性 DP
- 结果 = max(情况 A, 情况 B)

面试时如果提到这个变体，立刻加分。

### 4. 常见变体：二叉树房屋（House Robber III）

如果房屋结构变成二叉树，相邻节点不能同时偷？

**状态定义**：
- `dp[node][0]`：不偷当前节点的最大金额
- `dp[node][1]`：偷当前节点的最大金额

**状态转移**：
```
dp[node][0] = max(dp[left][0], dp[left][1]) + max(dp[right][0], dp[right][1])
dp[node][1] = node.val + dp[left][0] + dp[right][0]
```

这是树形 DP 的入门题，面试提到可以展示你对 DP 的扩展能力。

### 5. 一个面试坑：dp 数组到底要不要开 n+1？

打家劫舍的 dp 数组通常直接对应 `nums` 下标（0-based），不需要 `n+1`：
- `dp[0] = nums[0]`
- `dp[1] = max(nums[0], nums[1])`

但爬楼梯需要 `dp[n+1]`，因为 `dp[0]` 是地面。面试时别搞混，可以在定义状态时明确说明下标含义。
