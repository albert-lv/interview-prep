## 今日算法题

### 题目：不同路径

一个机器人位于一个 `m x n` 网格的左上角（起始点为 `(0, 0)`）。

机器人每次只能向下或向右移动一步。试图达到网格的右下角（终点为 `(m-1, n-1)`）。

问总共有多少条不同的路径？

**示例：**
```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 右 -> 下 -> 下
2. 下 -> 右 -> 下
3. 下 -> 下 -> 右
```

**进阶思考：** 如果网格中某些障碍物是 `1`，该如何处理？（LeetCode 63. 不同路径 II）

---

### 解题思路

这道题是从一维 DP 自然过渡到二维 DP 的经典桥梁题。核心观察：

**状态定义**
- `dp[i][j]` 表示从起点 `(0,0)` 到达 `(i,j)` 的不同路径数

**状态转移方程**
- 因为只能**向下**或**向右**走，所以到达 `(i,j)` 只能来自上方 `(i-1,j)` 或左方 `(i,j-1)`
- `dp[i][j] = dp[i-1][j] + dp[i][j-1]`

**初始化**
- 第一行 `dp[0][j] = 1`：只能一直向右走，路径唯一
- 第一列 `dp[i][0] = 1`：只能一直向下走，路径唯一

**一维优化（空间压缩）**
- 因为每个状态只依赖上方和左方，可以用一维数组滚动更新：`dp[j] = dp[j] + dp[j-1]`
- 空间复杂度从 `O(mn)` 降到 `O(n)`

---

### 代码示例

**标准二维 DP：**
```python
def uniquePaths(m: int, n: int) -> int:
    dp = [[1] * n for _ in range(m)]
    
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
    
    return dp[m-1][n-1]
```

**空间优化（一维）：**
```python
def uniquePaths(m: int, n: int) -> int:
    dp = [1] * n  # 初始化第一行
    
    for i in range(1, m):
        for j in range(1, n):
            dp[j] = dp[j] + dp[j-1]  # 上方 + 左方
    
    return dp[n-1]
```

**数学解法（组合数）：**
```python
import math

def uniquePaths_math(m: int, n: int) -> int:
    # 总共走 (m-1)+(n-1) 步，选其中 (m-1) 步向下
    return math.comb(m + n - 2, m - 1)
```

---

### 复杂度分析

| 维度 | 二维 DP | 一维优化 | 组合数 |
|------|---------|----------|--------|
| **时间** | `O(mn)` | `O(mn)` | `O(min(m,n))` |
| **空间** | `O(mn)` | `O(n)` | `O(1)` |

> 组合数解法最优雅，但面试中更考察你能否推导 DP。可以先写 DP，再提一嘴组合数作为加分项。

## 面试技巧

### 1. 如何从"不会做"聊到"有思路"

遇到 DP 题没思路时，不要冷场。可以按这个话术推进：

> "我先看看有没有明显的递归结构……每一步的选择会影响后续，那大概率是 DP。我先定义状态：设 `dp[i][j]` 为到达 `(i,j)` 的路径数……"

**关键话术：**
- "这道题看起来有**最优子结构** / **重叠子问题**"
- "我先画个小的例子找找规律……"
- "暴力解是指数级，有没有记忆化的空间？"

### 2. 二维 DP 的画图技巧

面试时如果紧张，**直接画表格**是最稳的：

```
  0 1 2 3  <- n=4
0 1 1 1 1
1 1 2 3 4
2 1 3 6 10
^
m=3
```

- 画完表格，递推关系自然浮现
- 面试官能看到你的思考过程，比直接给答案更有说服力

### 3. 空间优化的表达

如果面试官追问"能不能优化空间"：

> "可以。注意到 `dp[i][j]` 只依赖上方和左方，按行遍历时，左方的值已经算好，上方的值还在 `dp[j]` 里。所以一维数组就够了：`dp[j] += dp[j-1]`。"

> 这种表达展示了你对状态依赖关系的深刻理解，是加分项。
