## 一、今日算法题：0-1 背包问题

### 题目描述

给定 `n` 个物品，每个物品有一个重量 `weight[i]` 和一个价值 `value[i]`。现有一个容量为 `W` 的背包，**每个物品只能选择一次**（0-1 背包），问在不超过背包容量的前提下，能获得的最大价值是多少？

**示例**：
- weight = [2, 3, 4, 5], value = [3, 4, 5, 6], W = 8
- 输出：10（选物品 0 和 2，重量 2+4=6 ≤ 8，价值 3+5=8；或选物品 1 和 2，重量 3+4=7 ≤ 8，价值 4+5=9... 实际上最优解：选物品 0 和 1，重量 2+3=5，价值 3+4=7... 等等，让我重新算：

  - 选物品 0(2,3) + 物品 1(3,4) = 重量5, 价值7
  - 选物品 0(2,3) + 物品 2(4,5) = 重量6, 价值8
  - 选物品 0(2,3) + 物品 3(5,6) = 重量7, 价值9
  - 选物品 1(3,4) + 物品 2(4,5) = 重量7, 价值9
  - 选物品 1(3,4) + 物品 3(5,6) = 重量8, 价值10 ✓
  - 选物品 0(2,3) + 物品 1(3,4) + 物品 2(4,5) = 重量9 > 8，不行

  所以最大价值是 **10**。

### 思路分析

**核心思想**：这是一个经典的「选择型」DP——每个物品只有两种状态：选或不选。

**状态定义**：
- `dp[i][j]`：考虑前 `i` 个物品，背包容量为 `j` 时，能获得的最大价值

**状态转移方程**：
- 不选第 `i` 个物品：`dp[i][j] = dp[i-1][j]`（继承前 i-1 个物品的最优解）
- 选第 `i` 个物品：`dp[i][j] = dp[i-1][j-weight[i]] + value[i]`（前提：j ≥ weight[i]）
- 取两者最大值：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-weight[i]] + value[i])`

**优化——空间压缩**：
- 观察发现，第 `i` 行只依赖第 `i-1` 行，可以用一维数组 + 逆序遍历容量来压缩空间。

### 代码示例

```python
# 基础版：二维 DP
def knapsack_2d(weights, values, W):
    n = len(weights)
    # dp[i][j]：前 i 个物品，容量 j 的最大价值
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for j in range(W + 1):
            # 不选第 i-1 个物品（i 在代码中从 1 开始）
            dp[i][j] = dp[i-1][j]
            # 选第 i-1 个物品
            if j >= weights[i-1]:
                dp[i][j] = max(dp[i][j], 
                               dp[i-1][j-weights[i-1]] + values[i-1])
    
    return dp[n][W]

# 优化版：一维 DP（逆序遍历容量）
def knapsack_1d(weights, values, W):
    n = len(weights)
    dp = [0] * (W + 1)
    
    for i in range(n):
        # 必须逆序！否则同一件物品会被重复选（变成完全背包）
        for j in range(W, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[W]

# 如果需要还原选了哪些物品
# 额外维护一个 choice 数组，记录每个状态的选择
```

### 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二维 DP | O(n × W) | O(n × W) |
| 一维 DP（优化版） | O(n × W) | O(W) |

## 二、面试技巧

### 1. 面试官问 "这题怎么做？" 时，你的第一句话

不要直接说 "用 DP"。推荐结构：

> "这道题是一个组合优化问题，每个物品只有选/不选两种状态，总共有 2^n 种组合，暴力枚举不可行。我考虑用**动态规划**来避免重复计算，把问题拆解为『前 i 个物品，容量为 j』的子问题..."

**为什么好**：先解释**为什么用 DP**（最优子结构 + 重叠子问题），再解释**怎么用**，面试官会觉得你理解本质。

### 2. 写代码时，先写二维版本，再提优化

面试中，先写容易理解、不容易出错的二维版本，然后主动说：

> "这里可以优化空间，因为第 i 行只依赖第 i-1 行，我们可以用一维数组 + 逆序遍历..."

这样展示了你**先保证正确性，再考虑优化**的工程思维。

### 3. 逆序遍历是 0-1 背包的「灵魂考点」

面试官几乎一定会问：**为什么一维数组要逆序遍历容量？**

标准回答：
> "正序遍历会导致 `dp[j]` 被更新后，后续的 `dp[j + weights[i]]` 又会用到它，相当于同一件物品被选了多次，变成了完全背包问题。逆序遍历确保每个物品只被考虑一次。"

### 4. 常见变体与追问

面试中 0-1 背包常出现的变体：

| 变体 | 核心变化 | 应对思路 |
|------|---------|---------|
| **恰好装满** | 要求重量恰好等于 W | 初始化 `dp[0]=0`，其余为 `-inf`，最后判断 `dp[W]` 是否 ≥ 0 |
| **求方案数** | 问有多少种方案能达到最大价值 | `dp` 存最大价值，`count` 存方案数，同时更新 |
| **具体选了哪些物品** | 需要还原路径 | 额外维护 `choice[i][j]` 记录每个状态的决策 |
| **多约束背包**（如还有体积限制） | 两个维度限制 | 三维 DP：`dp[i][j][k]` 或压缩为二维 |

### 5. 一个面试小陷阱

不要一上来就写一维优化版！如果面试官让你解释状态定义，你连个 `dp[i][j]` 都没有，很难说清楚。二维版本是**解释思路的脚手架**，保留它，再过渡到优化。
