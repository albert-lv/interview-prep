# 每日面试备战 — Day 41（2026-07-16）

## 今日算法题：实现 Trie（前缀树）

> **LeetCode 208.** Implement Trie (Prefix Tree) — 高频面试原题，字节/阿里/腾讯均考

---

### 📋 题目描述

Trie（发音类似 "try"），又称**前缀树**或**字典树**，是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补完和拼写检查。

请你实现 Trie 类：

- `Trie()` — 初始化前缀树对象。
- `void insert(String word)` — 向前缀树中插入字符串 `word`。
- `boolean search(String word)` — 如果字符串 `word` 在前缀树中（即之前已插入过），返回 `true`；否则返回 `false`。
- `boolean startsWith(String prefix)` — 如果之前已插入的字符串中，有以 `prefix` 为前缀的，返回 `true`；否则返回 `false`。

**示例：**

```
输入：
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]

输出：
[null, null, true, false, true, null, true]

解释：
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False（"app" 未插入，只是前缀）
trie.startsWith("app"); // 返回 True（"apple" 以 "app" 开头）
trie.insert("app");
trie.search("app");     // 返回 True
```

---

### 💡 核心思路

Trie 的每个节点表示一个**字符路径**，从根节点到某个节点的路径就构成一个前缀。

**节点结构：**
- `children`：长度为 26 的数组（假设仅含小写字母），存放下一个字符的节点引用
- `isEnd`：布尔标记，表示从根到当前节点是否构成一个完整单词

**插入操作 `insert(word)`：**
1. 从根节点出发，遍历 `word` 的每个字符 `c`
2. 若当前节点的 `children[c]` 为空，则新建节点
3. 沿着 `children[c]` 移动到下一层
4. 遍历结束后，将最后一个节点的 `isEnd` 标记为 `True`

**查找操作 `search(word)`：**
1. 从根节点出发，沿字符路径遍历
2. 若某个字符对应的子节点为空，说明路径不存在，返回 `False`
3. 遍历完所有字符后，检查当前节点的 `isEnd` 是否为 `True`（必须是完整单词）

**前缀匹配 `startsWith(prefix)`：**
- 与 `search` 类似，但不需要检查 `isEnd`，只要路径存在即可

---

### 📝 代码实现（Python）

```python
class TrieNode:
    def __init__(self):
        self.children = [None] * 26  # 假设只存小写字母
        self.isEnd = False           # 标记是否是一个完整单词的结尾

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            idx = ord(ch) - ord('a')
            if node.children[idx] is None:
                node.children[idx] = TrieNode()
            node = node.children[idx]
        node.isEnd = True  # 标记单词结尾

    def search(self, word: str) -> bool:
        node = self._find(word)
        return node is not None and node.isEnd

    def startsWith(self, prefix: str) -> bool:
        return self._find(prefix) is not None

    def _find(self, word: str) -> TrieNode:
        """沿着 word 的路径查找，返回最后到达的节点（或 None）"""
        node = self.root
        for ch in word:
            idx = ord(ch) - ord('a')
            if node.children[idx] is None:
                return None
            node = node.children[idx]
        return node
```

---

### ⏱️ 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| `insert(word)` | O(m)，m 为单词长度 | O(m)（最坏情况下新建 m 个节点） |
| `search(word)` | O(m) | O(1) |
| `startsWith(prefix)` | O(m) | O(1) |

**与哈希表对比：**
- 哈希表 `search` 也是 O(m)，但 `startsWith` 需要 O(N) 遍历所有键
- Trie 的 `startsWith` 天然是 O(m)，这是 Trie 的核心优势

### 🎯 扩展：单词搜索 II（LeetCode 212）

Trie 的经典高阶应用题：在二维字符网格中查找所有单词。

**思路：** 将所有待查单词构建 Trie，然后从网格每个单元格出发 DFS，DFS 过程中在 Trie 上匹配路径。如果某路径在 Trie 中不存在，提前剪枝。遇到 `isEnd` 标记就记录一个单词。

**核心技巧：** 找到单词后，将该节点的 `isEnd` 设为 `False`（或删除节点），避免重复记录同一单词。

## 面试技巧

### 1️⃣ 如何判断面试官想要 Trie？

当题目出现以下关键词时，Trie 很可能是预期解法：
- **"前缀"** / **"prefix"** / **"startswith"**
- **"自动补全"** / **"autocomplete"**
- **"拼写检查"** / **"spell checker"**
- 大量字符串的**前缀匹配**或**公共前缀**问题
- 字符串集合需要频繁执行 `insert` + `startsWith` 组合操作

### 2️⃣ Trie 的面试话术模板

**开场（30 秒）：**
> "这道题涉及字符串的前缀匹配，我想到用 Trie（前缀树）来解决。Trie 的核心思想是共享前缀，把具有相同前缀的单词聚合到同一条路径上。"

**复杂度分析（关键加分点）：**
> "Trie 的查询和插入都是 O(m)，m 是单词长度，与 Trie 中已有多少单词无关。如果用哈希表做 `startsWith`，最坏要遍历所有键，是 O(N×m) 的。所以 Trie 在前缀查询场景下比哈希表更优。"

**空间优化（展示深度）：**
> "如果字符集很大（比如 Unicode），可以用 `HashMap` 或 `字典` 代替固定大小的数组来存 children，牺牲一点常数时间换取空间效率。另外如果数据量极大，还可以考虑**压缩 Trie**（将单分支路径压缩成一个节点）或**双数组 Trie**（用两个数组线性存储）。"

### 3️⃣ 面试官常见追问

| 追问 | 回答要点 |
|------|---------|
| "字符集不是 a-z 怎么办？" | 用 `dict`/`HashMap` 存 children，键是字符本身 |
| "Trie 比哈希表慢？" | 单次查询 Trie 是 O(m)，但哈希表 `startsWith` 是 O(N×m)。大量前缀查询时 Trie 占优 |
| "如何统计前缀出现次数？" | 每个节点加一个 `count` 字段，insert 时沿途 count++ |
| "如何删除一个单词？" | 沿路径找到单词节点，isEnd=False，然后递归清理无子节点且非单词结尾的节点 |
| "Trie 的内存占用？" | 最坏 O(N×m)，N 是单词数，m 是平均长度。共享前缀好的数据集实际远小于此 |

### 4️⃣ 白板coding注意事项

- **先画节点结构**：一个小方框，里面写 `children[26]`, `isEnd`，面试官一眼看懂
- **边写边解释**："每个节点代表一个字符位置，children 数组存下一个字符的引用"
- **`_find` 辅助函数**：把 search 和 startsWith 的公共逻辑抽出来，代码更简洁，体现工程意识
- **处理空字符串**：面试官可能挖坑，确认是否支持 `insert("")`，一般 `isEnd=True` 在根节点即可表示

> 💡 **一句话总结**：Trie = 用树结构共享字符串前缀，让 `startsWith` 从 O(N×m) 降到 O(m)。考场上看到"前缀"两个字，Trie 就是你要亮的武器。
