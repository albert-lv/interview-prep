## 今日算法题

### 题目描述

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。

求在该柱状图中，能够勾勒出来的**最大矩形面积**。

**示例：**
```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10（高度为 5，宽度为 2）
```

**约束：**
- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

---

### 核心思路：单调栈

这道题是**单调栈**的封神之作，面试出场率极高。

**关键观察：**
> 对于每个柱子 `heights[i]`，以它为高的最大矩形，其左右边界分别是**左边第一个比它矮的柱子**和**右边第一个比它矮的柱子**。

设左边界为 `left[i]`，右边界为 `right[i]`，则：
- 宽度 = `right[i] - left[i] - 1`
- 面积 = `heights[i] * 宽度`

**单调栈的作用：**
维护一个**单调递增栈**，栈中存储柱子的下标。当遇到比栈顶元素矮的柱子时，栈顶元素被"夹住"了——当前元素是它的右边界，新的栈顶是它的左边界。

**优化技巧 —— 哨兵法：**
在原数组首尾各加一个高度为 0 的虚拟柱子，这样保证所有真实柱子都能被弹出处理，代码更干净。

---

### 代码实现

```python
def largestRectangleArea(heights):
    # 哨兵法：两边补 0
    heights = [0] + heights + [0]
    n = len(heights)
    stack = []  # 单调递增栈，存下标
    max_area = 0
    
    for i in range(n):
        # 当前柱子比栈顶矮，栈顶元素的右边界确定
        while stack and heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]      # 栈顶柱子的高度
            left = stack[-1]               # 新的栈顶就是左边界
            width = i - left - 1           # 右边界是当前 i
            max_area = max(max_area, h * width)
        stack.append(i)
    
    return max_area
```

---

### 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | **O(n)** | 每个元素最多入栈、出栈各一次 |
| 空间 | **O(n)** | 栈空间 + 哨兵数组 |

> ⚠️ 暴力解 O(n²) 在 `10^5` 数据下必 TLE，单调栈是标准解法。

---

### 拓展：滑动窗口最大值（单调队列）

单调栈解决的是"**两侧最近更小/更大元素**"问题。

单调队列（deque 维护）解决的是"**滑动窗口最值**"问题：
```python
from collections import deque

def maxSlidingWindow(nums, k):
    q = deque()  # 存下标，对应值单调递减
    res = []
    for i, x in enumerate(nums):
        # 队尾元素比当前小，出队（它们不可能成为最大值了）
        while q and nums[q[-1]] <= x:
            q.pop()
        q.append(i)
        # 窗口左边界滑出
        if q[0] <= i - k:
            q.popleft()
        # 窗口形成后开始记录答案
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

**共同点：** 都是利用单调性"**提前淘汰不可能成为答案的元素**"，将 O(n²) 优化到 O(n)。

## 面试技巧

### 1. 遇到"找两侧最近更大/更小元素" → 条件反射单调栈

面试中如果题目出现这些关键词，先想单调栈：
- "下一个更大元素" / "下一个更小元素"
- "两侧最近的更大/更小"
- 矩形面积、接雨水（已做）、股票价格跨度

**模板口诀：**
> "比我矮的让我出栈，出栈时我能算面积，栈里剩下的就是我左边第一个比我矮的。"

### 2. 画图辅助讲解

面试官未必熟悉单调栈，**现场画个柱状图**，用指针走一遍栈的变化过程，是最有说服力的。

建议画法：
1. 画出数组 `[2,1,5,6,2,3]`
2. 走到 `i=1`（高度 1）时，栈里的 `0`（高度 2）被弹出
3. 现场标出 `left=-1`（哨兵），`right=1`，面积 = `2 * (1 - (-1) - 1) = 2`

### 3. 哨兵法的表述

> "我在数组两边各加了一个高度为 0 的柱子。这样所有真实柱子最终都会被弹出处理，不需要在循环结束后再清理栈里残留的元素，代码更简洁，也避免了边界特判。"

这种处理展示了你写"**鲁棒代码**"的习惯。

### 4. 从暴力到优化的叙述节奏

如果被追问"你怎么想到用单调栈的"，可以按这个逻辑答：
1. **暴力：** 对每个柱子，向左右扩展到不能扩展为止 → O(n²)
2. **瓶颈：** 每个柱子都在重复找"左右第一个比它矮的"
3. **优化：** 能不能一次遍历就确定这些信息？→ 用栈维护单调性，遇到更矮的就知道边界了
4. **升华：** 这就是"单调栈"的核心思想 —— 利用单调性一次性解决"最近更大/更小"问题

### 5. 延伸展示：单调栈 vs 单调队列

如果时间充裕，主动提一句：
> "类似的思路还有单调队列，比如滑动窗口最大值问题，也是 O(n) 解决，只是维护的是双端队列，处理的是滑动窗口的最值。"

这会让面试官觉得你对这类技巧有体系化理解，而不是背了一道题。
