## 一、今日算法题：信任瓶颈路径（Widest Path / 最大最小路径）

> **题目（复盘日综合题，LC 1102 思路的 agent 网络版）**：给定 n 个 agent 节点，每个节点有**信任分** `trust[i]`（0–100，来自 Day 176 的 attestation quorum 投票）；节点间有无向信道 `edges`（带传输成本，本题瓶颈题不用）。要求从 `src` 向 `dst` 传输一条秘密消息，**路径上每一跳的中继都必须是可信的**。定义一条路径的信任值为「路径上所有节点（含端点）信任分的**最小值**」（木桶效应：一条链的安全性 = 最弱一环）。求信任值最大的路径及其值。
>
> **变体（TTL 约束）**：若消息最多经过 `k` 次中转（≤k+1 条边，防环 + 控制爆炸半径），最优路径是什么？
>
> **变体（信任分来源）**：节点的信任分本身怎么算？—— 由邻居 agent 对它的 attestation 票流投票得出：> 2/3 票说「诚实」才具备可信中继资格（类比 LC 229 的 n/3 阈值 + PBFT 的 2f+1）。

```
trust = [90, 70, 30, 80, 60, 50]   // 节点 0..5 的信任分（30 分 = 已被 3 个监测器标记可疑）
edges: 0-1, 0-2, 1-3, 1-2, 2-3, 2-5, 3-4, 4-5
src=0, dst=5

无约束：  0→2→5        瓶颈 = min(90,30,50) = 30   ✗ 经过可疑节点 2
          0→1→3→4→5    瓶颈 = min(90,70,80,60,50) = 50 ✓ 最优
TTL=2：  0→2→5        瓶颈 = 30 ✓ 唯一可行（信任换跳数：约束越紧，可走路径越少，木桶水位越低）
```

### 思路：三算法合流 —— 一张信任图，三次投影

这道题是 Week 28 前半的**总复习**，一个解法里同时复用三天的核心工具：

**① 通信图层（Day 174）**：把 agent 网络建成带权图。节点信任分 = 图的「顶点容量」，这是 Day 174 的补充——LC 2092 只建模了边（什么时候传），没有建模节点本身可不可信。**多 agent 信任建模必须边权 + 顶点权双管齐下：顶点权失真（配置漂移、默认凭证、遗忘 key）就是 WeaveLotus 和 Cacti 事件的图论表述。**

**② 消息协议层（Day 175）**：无跳数约束的瓶颈路径 = **改造 Dijkstra**——最大堆替换最小堆，松弛操作从 `dist[u]+w` 换成 `min(dist[u], trust[v])`。贪心正确性与 Dijkstra 同构：目标函数对 `min` 单调，**一旦弹出堆的节点其瓶颈值即最终值**（任何绕路都必须先经过瓶颈 ≤ 当前值的节点）。**而 TTL 约束一变，子路径最优性再次失效**（同 LC 787 的教训），必须退回 **Bellman-Ford 按轮松弛 + 快照**：`dist[h][v]` = 至多 h 跳时的最大瓶颈。这就是 Day 175 的「约束挂整条路径」分水岭在瓶颈目标函数上的重演。

**③ 容错层（Day 176）**：信任分从哪来？每个节点被监测器网络持续 attestation，票流经 Boyer-Moore 家族计数：**「诚实」票 > 2/3 阈值才有可信中继资格**——把 LC 229 的 `> n/3` 阈值换成 `> 2n/3`（对应 PBFT 的 2f+1 诚实多数）。**于是整张信任图是一张会随时间变形的图：信任分每天重算，今天的最优路径明天可能因某节点被降权而改道——这就是瑞士 NCSC 案发现场需要的机制（被攻陷节点从图里动态摘除，路由自动绕开）。**

**复杂度**：瓶颈 Dijkstra O((n+m) log n) / O(n+m)；TTL 版 Bellman-Ford O(k·E) / O(n·k)——与 Day 175 完全一致，约束的代价永远体现在状态扩容上。

### Go 完整实现（实测 ✓）

```go
package main

import (
	"container/heap"
	"fmt"
)

type Edge struct{ to, cost int } // cost 留给成本版路由（Day 175），瓶颈题不用

type Item struct{ b, u int } // b = 当前到 u 的最佳瓶颈值
type MaxHeap []Item

func (h MaxHeap) Len() int            { return len(h) }
func (h MaxHeap) Less(i, j int) bool  { return h[i].b > h[j].b } // 最大堆
func (h MaxHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x interface{}) { *h = append(*h, x.(Item)) }
func (h *MaxHeap) Pop() interface{} {
	old := *h
	n := len(old)
	it := old[n-1]
	*h = old[:n-1]
	return it
}

// ① 无跳数约束：瓶颈 Dijkstra（最大堆 + min 松弛）
func widestPath(trust []int, adj [][]Edge, src, dst int) (int, []int) {
	n := len(trust)
	dist := make([]int, n)
	parent := make([]int, n)
	for i := range dist {
		dist[i], parent[i] = -1, -1
	}
	dist[src] = trust[src] // 路径瓶颈含端点自身信任分
	pq := &MaxHeap{{trust[src], src}}
	heap.Init(pq)
	for pq.Len() > 0 {
		top := heap.Pop(pq).(Item)
		b, u := top.b, top.u
		if b < dist[u] {
			continue // 过期条目（手写 Dijkstra 必查，Day 174 第三坑）
		}
		if u == dst {
			break // 最大堆特性：dst 首次弹出即最优
		}
		for _, e := range adj[u] {
			if nb := min(b, trust[e.to]); nb > dist[e.to] {
				dist[e.to], parent[e.to] = nb, u
				heap.Push(pq, Item{nb, e.to})
			}
		}
	}
	path := []int{}
	if dist[dst] >= 0 {
		for x := dst; x != -1; x = parent[x] {
			path = append([]int{x}, path...)
		}
	}
	return dist[dst], path
}

// ② TTL=k 次中转（≤k+1 条边）：Bellman-Ford 按轮快照松弛
func widestPathTTL(trust []int, adj [][]Edge, src, dst, k int) int {
	n := len(trust)
	dist := make([][]int, k+2) // dist[h][v] = 至多 h 跳时的最大瓶颈
	for h := range dist {
		dist[h] = make([]int, n)
		for i := range dist[h] {
			dist[h][i] = -1
		}
	}
	dist[0][src] = trust[src]
	for h := 1; h <= k+1; h++ {
		copy(dist[h], dist[h-1]) // 快照：允许「不用满跳数」
		for u := 0; u < n; u++ {
			if dist[h-1][u] == -1 {
				continue // INF 防御检查（Day 175 第三坑）
			}
			for _, e := range adj[u] {
				if nb := min(dist[h-1][u], trust[e.to]); nb > dist[h][e.to] {
					dist[h][e.to] = nb
				}
			}
		}
	}
	return dist[k+1][dst]
}

// ③ 信任分来源：attestation 票流的 Boyer-Moore 计数 + 2/3 quorum 阈值
func attestedTrust(votes []string, node string) (int, bool) {
	cnt := 0
	for _, v := range votes {
		if v == "honest:"+node {
			cnt++
		}
	}
	score := cnt * 100 / len(votes)
	return score, cnt*3 > len(votes)*2 // > 2n/3 才具备可信中继资格
}

func main() {
	trust := []int{90, 70, 30, 80, 60, 50} // 节点 2（30 分）= 被监测器标记可疑
	adj := [][]Edge{
		0: {{1, 2}, {2, 1}},
		1: {{0, 2}, {3, 3}, {2, 1}},
		2: {{0, 1}, {1, 1}, {3, 1}, {5, 2}},
		3: {{1, 3}, {2, 1}, {4, 1}},
		4: {{3, 1}, {5, 2}},
		5: {{4, 2}, {2, 2}},
	}
	b, path := widestPath(trust, adj, 0, 5)
	fmt.Println("无约束:  瓶颈信任分 =", b, "路径 =", path)           // 50 [0 1 3 4 5]
	fmt.Println("TTL=2:  瓶颈信任分 =", widestPathTTL(trust, adj, 0, 5, 2)) // 30（被迫走低信任捷径）
	fmt.Println("TTL=3:  瓶颈信任分 =", widestPathTTL(trust, adj, 0, 5, 3)) // 50（换回高信任路）
	s, ok := attestedTrust([]string{"honest:3", "honest:3", "honest:3", "honest:3",
		"honest:3", "honest:3", "honest:3", "honest:3", "honest:3", // 9 张诚实票
		"late:3", "absent:3", "unknown:3"}, "3") // + 3 张无效票，共 12 票
	fmt.Println("节点3 attestation: 信任分 =", s, "可信中继 =", ok) // 75 true
}
```

```
无约束:  瓶颈信任分 = 50 路径 = [0 1 3 4 5]
TTL=2:  瓶颈信任分 = 30
TTL=3:  瓶颈信任分 = 50
节点3 attestation: 信任分 = 75 可信中继 = true
```

### 面试三坑（复盘日的坑是「三天坑的总和」）

1. **用普通 Dijkstra 套瓶颈问题然后忘了改堆和松弛**——方向写反（最小堆求和）= 当场挂。被追问：「瓶颈目标的贪心为什么成立？」要答出 **min 的单调性**：绕路到 u 的任何路径必经过瓶颈 ≤ dist[u] 的节点，不可能后来居上。
2. **TTL 约束下继续用堆解**——子路径最优不保持（Day 175 原话复用），必须状态扩成 (节点, 已用跳数)。**同一个陷阱换目标函数再考你一遍，就是复盘的意义。**
3. **信任分当静态输入，忘了它是动态计算的**——面试官真正想听的是 ③：「trust[] 数组哪来的？」答「attestation 票流 Boyer-Moore 计数 + 2/3 quorum 阈值 + 定期重算」= 把 Day 176 接上了。**静态信任图 = 配置漂移的温床（Cacti guest 账户警告）。**

### 进阶六连

① **双目标（成本 + 信任）**：路径同时要求「瓶颈信任 ≥ τ 且总成本最小」→ **先删点（trust < τ 的节点全部摘除）再跑 Day 175 的 BF**——「先准入后优化」是信任路由的铁律：先 quarantine 再路由，顺序反了就是带病上岗。
② **信任分随时间衰减**：`trust_i(t) = score · λ^(t - lastAudit_i)`——久未审计的节点信任分自然衰减，迫使全网周期性重 attestation = 证书过期机制的投票版。
③ **多路径分片传输（Shamir 分片）**：秘密切 k 片走 **顶点不相交** 的 k 条路径，任一单点泄露不泄密 → 瓶颈问题升级为「最大化第 k 大瓶颈」——Menger 定理 + 最大流（Day 174 进阶⑤的最小割对偶上线）。
④ **拜占庭 attestation 攻击**：监测器自己不可信怎么办？**trust score 的计算本身跑在 3f+1 监测器 quorum 上**（PBFT 投票），监测器集群先于被监测者达成 2f+1 共识——递归的信任：信机器要先信「信机器的机器」。这就是黎曼猜想 Lean 验证链的拓扑（3 独立内核 × 数十复现）。
⑤ **在线版**：新节点动态入网、attestation 票流实时到达 → 信任图增量更新 + 局部重路由（受影响的最短路树子树），不需要全网重算 Dijkstra = 增量最短路（dynamic SPT）。
⑥ **工程落地形态**：服务网格（Istio/Linkerd）的 mTLS + 信任分路由 + SPIFFE/SPIRE 身份 = 本题的生产实现——面试时说「这套东西在服务网格里叫 trust domain 与 federation」，直接和 Swiss NCSC 案需要的防御对上号。

## 三、面试技巧（混合模拟面试 · 综合五连）

**Q1（30 分钟设计题）：给一家关键基础设施运营商设计「多 agent 信任路由网关」，把这三天的内容都用上。**
> 四澄清：① 网络规模与节点类型（内部 agent 数千 vs 跨组织上万）② 威胁模型（crash-fault 还是拜占庭——直接决定 quorum 层要不要）③ 延迟预算（实时控制流 vs 批量审计流）④ 合规要求（瑞士 NCSC/NIS2 事件上报时限）。
> 三层骨架：**L1 通信图**——全量 A2A/MCP 调用日志入图，节点 = agent NHI + 人类账号 + 服务账号（五角大楼教训：agent 必须有独立身份），边 = 带时间戳的调用关系，每日跑爆炸半径分析（LC 2092）；**L2 协议**——mTLS + 消息签名 + TTL 上限 + 幂等键，跨信任域信道加安全税（LC 787）；**L3 容错**——每节点 attestation 票流 Boyer-Moore 计数，> 2/3 准入，< 阈值自动 quarantine（今天的主算法），quorum 由 3f+1 监测器集群 PBFT 裁定。
> 收尾加分：被 quarantine 节点的在途消息不杀——进死信队列按 Merkle 链审计后回放或丢弃（Day 168 遗产）。

**Q2：瑞士确认 AI agent 攻破关键基础设施（4/5 起用 AI），如果你是受害企业 CTO，72 小时应急怎么做？**
> 三步走：**止血（0–4h）**——按通信图爆炸半径隔离受影响 NHI（不是按 IP，按身份），瑞士案 2 起得手 = 隔离窗口已经错过，但防的是第二拨；**画图（4–24h）**——审计日志重建 (src_agent, 时间窗) session-graph，AI agent 攻击 = 单事件全合规、序列整体恶意（Day 175 的 ARTEX 判定标准），检测单元从 request 升级成 session-graph；**补票（24–72h）**——attestation 全量重投、信任分重算、τ 阈值临时上调（今天的双目标①：先删点后路由，宁可业务降速不带病上岗），并向 NCSC 提交「合理防护措施」证据链（白宫新政：有证据链才能换监管宽恕）。

**Q3：黑五战报——agentic 订单 109×、客单价 $231 vs 直接购买 $105，零售网关要不要收紧 agent 流量？**
> 不要一刀切，用三层数据说话：**身份**（Visa TAP 签名 agent 进 fast lane 带配额；未签名自动化进渐进验证 lane——Forter 的教训：好 agent 坏 bot 行为指纹 identical，只能按身份分）；**意图**（读操作比价宽进 + 强缓存，写操作下单/支付必须 EMVCo scope token + 用户绑定速率——$231 高客单价 = agent 在替人买贵东西，拦错一个真客户损失 > 放错十个坏 bot）；**信任分联动**（agent 的 scope token 行为偏离 attestation 基线 → 信任分降级 → 路由到 challenge lane = 今天的动态信任图实战）。**结论：不是「收不收紧」而是「谁值得信任」——信任分是唯一正确的调节旋钮。**

**Q4：WeaveLotus 用默认凭证 + 旧漏洞连打五家东南亚军方，这和算法题什么关系？**
> 默认凭证 = **通信图里一条权重被当成 +∞（不可达）但实际存在的边**——LC 2092 的传播分析会漏掉这条边，爆炸半径算小。工程解：L1 层的资产发现必须包含「凭证面」（默认口令扫描、guest surface 探测、debug 模式暴露检查），扫描结果**直接改写图的边集**，不信任任何人工申报的图。Cacti 的 guest 账户（默认关闭但生产漂移开启）同理：**信任图必须是测量出来的，不能是申报出来的。** 一句话收尾：「配置漂移 = 图快照失真，而失真的图比没有图更危险——它给你虚假的安全感。」

**Q5：管理层问「我们的 AI 系统到底安不安全」，用三句话回答。**
> ① 「**信息能流到谁**」——我有全量通信图，任一凭证泄露 5 分钟内给出爆炸半径清单（L1，LC 2092）；② 「**每条消息可不可信**」——所有跨域消息带 NHI 签名 + TTL + 幂等，幻影信道有 canary 检测（L2，Day 175）；③ 「**节点还可不可信**」——每个 agent 有动态信任分，低于 2/3  quorum 自动摘除，quorum 本身由 3f+1 监测器裁定（L3，Day 176 + 今日算法）。**三层各有一个可演示的指标 = 白宫「合理防护措施」的证据链本体。**
