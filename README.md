# Interview Prep

每日面试准备：算法题 + 面试技巧。

- 计划：6 周系统冲刺
- 更新：每天晚上自动生成
- 格式：Markdown，按周归档

## 目录结构

```
week01/YYYY-MM-DD-topic.md
```

## 周计划（穿插式）

| 周 | 周一 | 周三 | 周五 |
|---|---|---|---|
| Week 1 | DP 入门 | 数组/字符串 | DP 进阶 |
| Week 2 | 线性 DP | 链表/栈/队列 | 线性 DP 进阶 |
| Week 3 | 树形 DP | 树/BFS/DFS | 区间 DP |
| Week 4 | 状态压缩 DP | 图论/二分/滑动窗口 | DP 优化 |
| Week 5 | DP 高频 | 贪心/回溯 | 模拟实战 |
| Week 6 | 综合真题 | 系统设计/场景题 | 模拟面试 |

**节奏**：周一/周五主菜 DP，周三换口味数据结构/算法，周六复盘，周日休息。
