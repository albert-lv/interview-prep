## 今日算法题

### 题目描述（LeetCode 943 / 经典模板题）

给定 `n` 个城市（编号 `0` 到 `n-1`），以及每对城市之间的距离 `dist[i][j]`（无向图， dist[i][j] = dist[j][i]）。

求：从**城市 0** 出发，**恰好经过每个城市一次**，最终可以停在任意城市的**最短路径长度**。

> 这就是著名的 **Hamilton 路径** 问题，是理解状态压缩 DP 的最佳入门题。

**示例：**

```
输入：dist = [
  [0, 2, 6, 5],
  [2, 0, 4, 4],
  [6, 4, 0, 2],
  [5, 4, 2, 0]
]

输出：11
解释：0 -> 1 -> 3 -> 2，总长度 = 2 + 4 + 2 = 8
      或者 0 -> 2 -> 3 -> 1，总长度 = 6 + 2 + 4 = 12
      最短为 8（0->1->3->2）或 0->2->3->1 的反向等价路径
```

---

### 解题思路：状态压缩 DP

#### 为什么普通 DP 不够？

如果只用 `dp[i]` 表示"到城市 i 的最短距离"，我们**丢失了访问历史**——不知道哪些城市已经去过，可能会重复访问。而 Hamilton 路径要求每个城市只走一次。

#### 核心洞察：用 bitmask 表示集合

`n` 个城市最多 20 个，我们可以用一个整数的二进制位来表示「哪些城市已经访问过」：

- 若第 `i` 位为 1，表示城市 `i` 已访问
- 若第 `i` 位为 0，表示城市 `i` 未访问

例如：`mask = 0b1011`（二进制）= 11（十进制），表示城市 0、1、3 已访问，城市 2 未访问。

#### 状态定义

```
dp[mask][i] = 从城市 0 出发，已经访问过的城市集合为 mask，
              且当前位于城市 i 的最短路径长度
```

- `mask` 的范围：`0` 到 `(1 << n) - 1`
- `i` 的范围：`0` 到 `n-1`
- 条件：城市 0 和 城市 i 必须在 mask 中

#### 状态转移

假设当前在 `mask` 状态、位于城市 `i`。上一个城市一定是某个 `j`（`j ≠ i`，且 `j` 也在 mask 中）：

```
dp[mask][i] = min(
    dp[mask ^ (1 << i)][j] + dist[j][i]
)  对所有满足条件的 j
```

解释：`mask ^ (1 << i)` 就是把城市 `i` 从集合中「去掉」，得到上一个状态。

#### 初始化

```
dp[1 << 0][0] = 0   // 只访问了城市 0，当前就在城市 0，距离为 0
其余所有状态初始化为 INF
```

#### 最终答案

```
answer = min(dp[(1 << n) - 1][i])  对所有 i（0 <= i < n）
```

即：所有城市都访问过了（mask 全为 1），停在哪个城市都可以，取最小值。

---

### 代码实现（Python）

```python
def shortestHamiltonPath(dist):
    n = len(dist)
    INF = float('inf')
    
    # dp[mask][i]: 已访问集合为 mask，当前在城市 i 的最短距离
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1 << 0][0] = 0  # 起点：只访问了城市 0
    
    # 枚举所有状态 mask
    for mask in range(1 << n):
        # 枚举当前所在城市 i
        for i in range(n):
            # 状态无效：i 不在 mask 中，或者 0 不在 mask 中（必须从 0 出发）
            if not (mask & (1 << i)) or not (mask & 1):
                continue
            
            # 枚举上一个城市 j
            for j in range(n):
                if i == j or not (mask & (1 << j)):
                    continue
                prev_mask = mask ^ (1 << i)
                dp[mask][i] = min(dp[mask][i], dp[prev_mask][j] + dist[j][i])
    
    # 所有城市都访问过，停在任意城市的最小值
    full_mask = (1 << n) - 1
    return min(dp[full_mask][i] for i in range(n))


# 测试
dist = [
    [0, 2, 6, 5],
    [2, 0, 4, 4],
    [6, 4, 0, 2],
    [5, 4, 2, 0]
]
print(shortestHamiltonPath(dist))  # 输出: 8
```

---

### 空间优化：滚动数组技巧

注意到 `dp[mask]` 只依赖于 `dp[mask 去掉一个位]` 的状态，也就是比 `mask` 小的状态。所以正着枚举 `mask` 即可，不需要额外的滚动优化。

但如果题目要求**必须回到起点**（TSP 环路版），最终答案是 `dp[full_mask][0]`，且转移时需要额外考虑从 `i` 回到 `0` 的距离。

---

### 复杂度分析

| 维度 | 值 | 说明 |
|------|---|------|
| **时间复杂度** | `O(n² × 2ⁿ)` | `2ⁿ` 个状态 × `n` 个终点 × `n` 个前驱点 |
| **空间复杂度** | `O(n × 2ⁿ)` | `dp` 数组大小 |

> ⚠️ **关键限制**：`n ≤ 20` 是状态压缩 DP 的隐形天花板。`2²⁰ ≈ 100万`，可以接受；`2²⁵ ≈ 3300万` 就爆炸了。面试时先判断数据范围！

## 面试技巧

### 1. 如何识别「状态压缩 DP」题目？

面试官不会告诉你"请用状态压缩"。你需要自己嗅探到这些信号：

| 信号 | 说明 |
|------|------|
| **n ≤ 20** | 最常见的暗示！刚好在 `2ⁿ` 可接受的边缘 |
| **集合选择/排列问题** | "从 n 个元素中选一些"、"每个只能用一次" |
| **游戏状态** | 棋盘上的棋子摆放、数字已被选取的记录 |
| **需要记住访问历史** | 路径不能重复、状态依赖已访问的节点集合 |

> 经典话术："这题数据范围 `n ≤ 15`，我考虑用状态压缩动态规划，用一个整数的二进制位来表示集合状态……"

### 2. bitmask 操作速查表

```python
# 核心操作（面试时直接写，不用解释太多）
mask | (1 << i)    # 将第 i 位设为 1（加入城市 i）
mask & ~(1 << i)   # 将第 i 位设为 0（移除城市 i）
mask ^ (1 << i)    # 翻转第 i 位
mask & (1 << i)    # 检查第 i 位是否为 1（城市 i 是否在集合中）
mask >> i & 1      # 同上，另一种写法

# 枚举子集（高阶技巧）
sub = mask
while sub:
    sub = (sub - 1) & mask  # 枚举 mask 的所有非空子集
```

**面试官**："这题怎么做？"

**你**（展现思考过程）：
> "首先，`n` 个城市全排列有 `n!` 种，暴力枚举肯定不行。
> 
> 但注意到 `n ≤ 20`，这让我想到**状态压缩**——用一个整数的二进制位来表示「哪些城市已经访问过」。
>
> 定义 `dp[mask][i]` 为已访问集合 `mask`、当前在城市 `i` 的最短路径。
> 状态数是 `n × 2ⁿ`，大概在百万级别，可以接受。
> 
> 转移时，我从所有可能的前驱城市 `j` 转移过来……"

**为什么这样说好**：
- 先展示你对复杂度的直觉（`n!` 不可行）
- 再引出关键观察（`n ≤ 20` → 状态压缩）
- 最后给出清晰的状态定义和转移方程

---

### 4. 常见踩坑点

| 坑 | 怎么避免 |
|---|---------|
| 忘记检查 `i` 是否在 `mask` 中 | 每次枚举 `i` 前先 `if mask >> i & 1` |
| 起点必须是城市 0 | 初始化时只设 `dp[1][0] = 0`，枚举时检查 `mask & 1` |
| INF 加距离溢出 | 转移前判断 `dp[prev][j] != INF` |
| 把 TSP 路径版和环路版搞混 | 路径版答案 = `min(dp[full][i])`；环路版 = `dp[full][0]` |

---

### 5. 面试官可能追问

- **Q**：空间复杂度能优化吗？  
  **A**：如果转移只依赖更小的 mask，可以按 mask 递增枚举，但空间仍是 `O(n × 2ⁿ)`。如果用 `short` 或滚动数组优化，能省一点但量级不变。

- **Q**：`n = 25` 怎么办？  
  **A**：`2²⁵ = 3300万` 状态，时间和空间都爆炸。需要换思路——可能是 meet-in-the-middle（折半搜索）或者近似算法（如贪心、模拟退火）。

- **Q**：如果图是有向的呢？  
  **A**：代码完全不需要改！`dist[j][i]` 本来就不是对称的，状态压缩 DP 对有向无向都适用。

```
状态压缩 DP = 小规模集合问题（n ≤ 20）的杀手锏
核心武器：用 bitmask（整数二进制位）代替集合
状态设计：dp[mask][i] = 在 mask 状态下，位于节点 i 的最优值
转移关键：从「去掉 i 的 mask」转移过来
```
