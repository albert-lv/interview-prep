## 一、今日算法题

### 题目描述（LeetCode 152）

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

**示例 1：**
```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

**示例 2：**
```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2，因为 [-2,-1] 不是子数组（不连续，中间隔了0）。
```

**约束条件：**
- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何前缀或后缀的乘积都保证在 **32 位** 整数范围内

---

### 思路分析

这道题表面看和「最大子数组和」（Day 9）很像，但有一个**致命陷阱**：

> **负数 × 负数 = 正数**

这意味着当前位置的最小乘积，可能在下一个负数到来时变成最大乘积。

#### ❌ 错误思路：直接套用「最大子数组和」

```python
def maxProduct_wrong(nums):
    n = len(nums)
    dp = [0] * n
    dp[0] = nums[0]
    
    for i in range(1, n):
        # 这样是错的！没有考虑负数翻盘的场景
        dp[i] = max(nums[i], dp[i-1] * nums[i])
    
    return max(dp)
```

反例：`nums = [-2, 3, -4]`
- 正确答案是 `(-2) × 3 × (-4) = 24`
- 但错误解法只关注最大值，会错过这个组合

---

#### ✅ 正确思路：同时维护「最大值」和「最小值」

核心洞察：
> 因为负号会让大小翻转，所以我们需要同时知道**以当前位置结尾的最大乘积**和**以当前位置结尾的最小乘积**。

定义状态：
- `max_dp[i]`：以 `nums[i]` 结尾的连续子数组的最大乘积
- `min_dp[i]`：以 `nums[i]` 结尾的连续子数组的最小乘积

状态转移：
```
如果 nums[i] > 0:
    max_dp[i] = max(nums[i], max_dp[i-1] * nums[i])
    min_dp[i] = min(nums[i], min_dp[i-1] * nums[i])

如果 nums[i] < 0:
    max_dp[i] = max(nums[i], min_dp[i-1] * nums[i])  # 注意这里是 min_dp！
    min_dp[i] = min(nums[i], max_dp[i-1] * nums[i])  # 注意这里是 max_dp！

如果 nums[i] == 0:
    max_dp[i] = 0
    min_dp[i] = 0
```

**为什么这样？**
- 正数：延续之前的最大值/最小值自然是对的
- 负数：之前的**最小值**（最负的）乘上负数，反而变成最大值
- 0：一切归零，重新开始

---

### 代码实现

#### 方法一：动态规划（O(n) 时间，O(n) 空间）

```python
def maxProduct(nums):
    n = len(nums)
    if n == 0:
        return 0
    
    # dp_max[i] = 以 nums[i] 结尾的最大乘积
    # dp_min[i] = 以 nums[i] 结尾的最小乘积
    dp_max = [0] * n
    dp_min = [0] * n
    
    dp_max[0] = nums[0]
    dp_min[0] = nums[0]
    
    for i in range(1, n):
        if nums[i] > 0:
            dp_max[i] = max(nums[i], dp_max[i-1] * nums[i])
            dp_min[i] = min(nums[i], dp_min[i-1] * nums[i])
        elif nums[i] < 0:
            dp_max[i] = max(nums[i], dp_min[i-1] * nums[i])
            dp_min[i] = min(nums[i], dp_max[i-1] * nums[i])
        else:  # nums[i] == 0
            dp_max[i] = 0
            dp_min[i] = 0
    
    return max(dp_max)
```

#### 方法二：空间优化（O(n) 时间，O(1) 空间）⭐ 面试推荐

观察发现，计算 `dp[i]` 只需要 `dp[i-1]`，所以可以用滚动变量：

```python
def maxProduct_optimized(nums):
    if not nums:
        return 0
    
    # 初始化：当前位置的最大/最小乘积
    curr_max = nums[0]
    curr_min = nums[0]
    result = nums[0]
    
    for i in range(1, len(nums)):
        num = nums[i]
        
        # 核心：负数会让最大最小翻转，所以一起更新
        # 技巧：先保存旧的 curr_max，因为更新 curr_min 时还需要用
        prev_max = curr_max
        
        curr_max = max(num, curr_max * num, curr_min * num)
        curr_min = min(num, prev_max * num, curr_min * num)
        
        # 更新全局答案
        result = max(result, curr_max)
    
    return result
```

**代码要点：**
1. `prev_max` 必须先保存，因为 `curr_min` 的计算依赖旧的 `curr_max`
2. 每个位置都有三种选择：
   - `num`：从当前位置重新开始
   - `curr_max * num`：延续之前的最大值
   - `curr_min * num`：延续之前的最小值（负数时可能翻盘）

---

### 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 面试定位 |
|------|-----------|-----------|----------|
| DP 数组版 | O(n) | O(n) | 容易理解，适合先讲 |
| 滚动变量版 | O(n) | O(1) | **面试推荐写法**，简洁高效 |

### 手动 Trace 示例

以 `nums = [2, 3, -2, 4]` 为例：

```
初始化: curr_max=2, curr_min=2, result=2

i=1, num=3:
  prev_max = 2
  curr_max = max(3, 2*3, 2*3) = max(3, 6, 6) = 6
  curr_min = min(3, 2*3, 2*3) = min(3, 6, 6) = 3
  result = max(2, 6) = 6

i=2, num=-2:
  prev_max = 6
  curr_max = max(-2, 6*(-2), 3*(-2)) = max(-2, -12, -6) = -2  ← 负数来了，最大值变成 -2
  curr_min = min(-2, 6*(-2), 3*(-2)) = min(-2, -12, -6) = -12  ← 最小值变成 -12（最负）
  result = max(6, -2) = 6

i=3, num=4:
  prev_max = -2
  curr_max = max(4, (-2)*4, (-12)*4) = max(4, -8, -48) = 4   ← 等等，这不对...
```

**发现问题！** 上面的 trace 有问题。让我重新算：

```
i=3, num=4:
  prev_max = -2
  curr_max = max(4, (-2)*4, (-12)*4) = max(4, -8, -48) = 4
  curr_min = min(4, (-2)*4, (-12)*4) = min(4, -8, -48) = -48
  result = max(6, 4) = 6
```

但正确答案是 `3 * (-2) * 4 = -24`... 不对，正确答案应该是 `2 * 3 = 6`。

让我重新验证：
- `[2]` = 2
- `[2,3]` = 6
- `[2,3,-2]` = -12
- `[2,3,-2,4]` = -48
- `[3]` = 3
- `[3,-2]` = -6
- `[3,-2,4]` = -24
- `[-2]` = -2
- `[-2,4]` = -8
- `[4]` = 4

最大确实是 6，正确。

## 二、面试技巧

### 🎯 技巧 1：为什么这道题不能直接用「最大子数组和」的思路？

面试中，如果之前做过「最大子数组和」，很容易惯性思维直接套用。但要注意：

| 维度 | 最大子数组和 | 乘积最大子数组 |
|------|-------------|---------------|
| 符号影响 | 无（加法） | **有（负负得正）** |
| 状态数 | 1个（最大） | **2个（最大+最小）** |
| 0 的处理 | 忽略或重置 | 强制归零 |

**面试话术：**
> "这道题和最大子数组和很像，但有个关键区别——乘积遇到负数会翻转大小关系。所以我需要同时维护以当前位置结尾的最大乘积和最小乘积，这样遇到下一个负数时，之前的最小乘积就可能变成最大乘积。"

---

### 🎯 技巧 2：DP 状态设计的「翻转思维」

这道题的核心优化在于**状态设计的扩展**：

```
普通 DP：只关心「最优」→ 一个状态
进阶 DP：「最优」和「最劣」都要关心 → 两个状态
```

什么时候需要这种扩展？
- **符号会翻转**：乘积中的负数
- **操作可逆**：某些博弈问题
- **需要次优解**：次大/次小可能在未来变成最优

**类似题目：**
- 买卖股票的最佳时机（需要同时维护「持有」和「不持有」两种状态）
- 打家劫舍 II（需要同时维护「偷第一家」和「不偷第一家」两种情况）

---

### 🎯 技巧 3：空间优化的「滚动变量」技巧

面试中，O(1) 空间的写法更受欢迎：

```python
# 技巧：用临时变量保存旧值，避免覆盖
prev_max = curr_max
curr_max = max(num, curr_max * num, curr_min * num)
curr_min = min(num, prev_max * num, curr_min * num)
```

**常见错误：** 不写 `prev_max`，直接用更新后的 `curr_max` 去算 `curr_min`。

**面试安全写法：** 如果不确定，先写 O(n) 空间版本，然后对面试官说："这里可以优化到 O(1) 空间，因为每次只依赖前一个状态，需要我优化吗？"

---

### 🎯 技巧 4：处理边界情况

这道题有几个容易忽略的边界：

1. **数组只有一个元素**：直接返回 `nums[0]`
2. **数组全是负数**：如 `[-2]`，返回 -2
3. **数组包含 0**：如 `[-2, 0, -1]`，0 会截断连续性
4. **最大乘积可能是负数**：如 `[-2]`，不要默认初始化为 0

**测试用例清单（面试时可以主动提）：**
```
[2,3,-2,4]     # 正常情况，答案 6
[-2]           # 单元素负数
[0, -2, -3]    # 0 截断
[-2, 0, -1]    # 0 截断，答案 0（不是 2）
[2, -5, -2, -4, 3]  # 多重负号翻转
```

---

### 🎯 技巧 5：从暴力到最优的叙述节奏

```
面试官：给你这个数组，找乘积最大的连续子数组。

你：好，我先理解一下——「连续子数组」意味着必须相邻，不能跳。
    最暴力的方法是枚举所有子数组，O(n²)，然后找最大乘积。
    
面试官：能不能优化？

你：可以。观察到一个规律：以位置 i 结尾的子数组，要么只包含 nums[i]，
    要么是在以 i-1 结尾的子数组后面追加 nums[i]。
    所以这是一个 DP 问题。
    
    但有个陷阱：乘积和加法不同，负数会让大小翻转。
    比如 [-2, 3, -4]，如果只看最大值，会错过 (-2)×3×(-4)=24。
    所以我需要同时维护两个状态：
    - dp_max[i]：以 i 结尾的最大乘积
    - dp_min[i]：以 i 结尾的最小乘积（负数来时可能翻盘）
    
    这样时间 O(n)，空间可以优化到 O(1)。
```
