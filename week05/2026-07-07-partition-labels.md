## 今日算法题

### 题目描述

字符串 `S` 由小写字母组成。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。返回一个表示每个字符串片段的长度的列表。

**示例:**
```
输入: S = "ababcbacadefegdehijhklij"
输出: [9,7,8]
解释:
- 划分结果为 "ababcbaca", "defegde", "hijhklij"
- 同一字母不会出现在多个片段中
- 注意：划分需保证连续，且尽量多片段
```

### 思路分析

这道题是典型的**贪心 + 哈希表**组合。核心洞察：

> 如果一个字母在位置 `i` 出现，那么包含这个字母的片段**至少要延伸到它最后一次出现的位置**。

**步骤:**
1. **预处理**: 先遍历一遍字符串，用哈希表记录每个字母**最后出现的位置**（`last[char] = index`）
2. **贪心划分**: 再次遍历，维护当前片段的**结束边界** `end`:
   - 每遇到一个新字符，更新 `end = max(end, last[char])`
   - 当遍历位置 `i == end` 时，说明当前片段已经包含了所有需要的字母，可以在此处切分
   - 切分后，更新下一个片段的起始位置

**为什么贪心正确？** 因为当我们确定了一个片段的起始位置后，为了"同一字母不出现在多个片段"，这个片段的右边界必须覆盖所有已出现字母的最远位置。而我们在遍历过程中不断扩展这个边界，当走到边界时强制切分，就能得到**最多片段数**（因为每个片段都尽可能小）。

### 代码实现（Python）

```python
def partitionLabels(s: str) -> list[int]:
    # 1. 记录每个字母最后出现的位置
    last = {}
    for i, ch in enumerate(s):
        last[ch] = i
    
    # 2. 贪心划分
    result = []
    start = 0      # 当前片段起始
    end = 0        # 当前片段必须延伸到的最右位置
    
    for i, ch in enumerate(s):
        end = max(end, last[ch])  # 扩展当前片段的边界
        
        if i == end:               # 到达边界，可以切分
            result.append(end - start + 1)
            start = i + 1          # 下一个片段从 i+1 开始
    
    return result
```

### 复杂度分析

- **时间复杂度**: O(n)，两次遍历字符串，每次 O(n)
- **空间复杂度**: O(1)，哈希表最多存 26 个小写字母，视为常数空间；输出数组不计入额外空间的话是 O(1)

### 手写推演

以 `"ababcbacadefegdehijhklij"` 为例：

| 字母 | 最后位置 |
|------|----------|
| a    | 8        |
| b    | 5        |
| c    | 7        |
| d    | 14       |
| e    | 15       |
| f    | 11       |
| g    | 13       |
| ...  | ...      |

遍历过程:
- i=0, 'a', end=max(0,8)=8; i≠end, 继续
- i=1, 'b', end=max(8,5)=8; i≠end, 继续
- ...
- i=8, 'a', end=max(8,8)=8; **i==end!** 切分片段长度=9
- 重置 start=9, 继续处理 "defegde"...

## 面试技巧

### 1. 如何向面试官解释贪心算法的正确性？

贪心题最危险的点就是面试官问你"为什么这样 greedy 是对的"。别慌，有固定话术：

> **"我的策略每一步都做出了局部最优选择，而这个问题的最优子结构保证了局部最优能推导出全局最优。具体来说..."**

然后解释你的"选择标准"和"为什么不会错过更优解"。

以本题为例：
- **选择标准**: 当前片段必须覆盖所有已出现字母的最远位置
- **为什么不会错过**: 如果不覆盖最远位置，某个字母就会跨片段，违反约束。而当覆盖后立刻切分，保证了每个片段最小化，从而片段数最大化。

### 2. 面试中说"两次遍历"的节奏感

这道题天然分两步，非常适合在面试中展示**结构化思维**：

1. 第一步：先预处理，把"每个字母最远出现在哪"算出来（给面试官画个小表）
2. 第二步：再遍历，用贪心切分（在纸上画 end 指针怎么移动）

面试官喜欢这种"先讲清楚思路，再写代码"的节奏，而不是闷头就写。

### 3. 边界条件 checklist

写完代码后主动提一句：
- 字符串长度为 1 时？→ 返回 `[1]`，代码自然处理
- 所有字母都不同？→ 每个字母一个片段，也是对的
- 所有字母都相同？→ 返回 `[n]`，end 会一直扩展到 n-1
- 只包含小写字母？→ 题目约束，不用处理大写/数字

主动提边界，面试官会默默给你加分。

### 4. 一句话总结

> **"先找每个字母的右边界，再贪心扩展、到边界就切"** — 这句话说出来，面试官就知道你懂了。
