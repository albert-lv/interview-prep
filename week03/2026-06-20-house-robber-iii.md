## 📝 题目描述

小偷又发现了一个新的可行窃的地区。这个地区只有一个入口，称之为 `root`。

除了 `root` 之外，每栋房子有且只有一个“父“房子与之相连。一番侦察之后，聪明的小偷意识到“这个地方的所有房屋的排列类似于一棵二叉树”。如果 **两个直接相连的房子在同一天晚上被打劫** ，房屋将自动报警。

给定一棵二叉树的根节点 `root`，返回 **在不触动警报的情况下** ，小偷能够盗取的最高金额。

**示例**:
```
输入: root = [3,2,3,null,3,null,1]
    3
   / \
  2   3
   \   \
    3   1

输出: 7
解释: 小偷一晚能够盗取的最高金额 = 3 + 3 + 1 = 7
```

---

## 💡 核心思路

打家劫舍 III 是**树形DP**的入门经典题。它把线性DP（打家劫舍 I）扩展到了二叉树上：

| 版本 | 结构 | 核心约束 |
|------|------|----------|
| 打家劫舍 I | 线性数组 | 不能偷相邻两个房子 |
| 打家劫舍 III | **二叉树** | 不能偷**直接相连**的两个节点（父子不能同时偷） |

### 关键观察

对于每个节点，只有两种状态：
- **偷这个节点**：那么它的左右子节点**不能偷**
- **不偷这个节点**：那么它的左右子节点**可偷可不偷**，取最优

### 状态定义

对每个节点 `node`，定义一个二元组：

```
dp[node] = (偷当前节点的最大收益, 不偷当前节点的最大收益)
```

### 状态转移

```
// 如果偷当前节点：左右子节点都不能偷
dp[node][0] = node.val + dp[left][1] + dp[right][1]

// 如果不偷当前节点：左右子节点可偷可不偷，取各自最优
dp[node][1] = max(dp[left][0], dp[left][1]) + max(dp[right][0], dp[right][1])
```

> 用大白话讲：**偷了爹，就不能偷儿子；不偷爹，儿子们爱偷不偷，我不管。**

### 遍历顺序：后序遍历

因为父节点的状态依赖于子节点的状态，所以必须**先算子节点，再算父节点** → 这就是后序遍历（左→右→根）。

---

## 🖥️ 代码实现

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rob(self, root: TreeNode) -> int:
        
        def dfs(node):
            """
            返回 (偷当前节点的最大收益, 不偷当前节点的最大收益)
            """
            if not node:
                # 空节点：偷了0收益，不偷也是0收益
                return (0, 0)
            
            # 后序遍历：先递归处理左右子树
            left_steal, left_skip = dfs(node.left)
            right_steal, right_skip = dfs(node.right)
            
            # 偷当前节点：不能偷左右子节点
            steal = node.val + left_skip + right_skip
            
            # 不偷当前节点：左右子节点可偷可不偷，取最优
            skip = max(left_steal, left_skip) + max(right_steal, right_skip)
            
            return (steal, skip)
        
        # 返回根节点偷或不偷的较大值
        return max(dfs(root))


# 验证
root = TreeNode(3)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.right = TreeNode(3)
root.right.right = TreeNode(1)

sol = Solution()
print(sol.rob(root))  # 输出: 7
```

## ⏱️ 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **时间** | O(n) | 每个节点只访问一次 |
| **空间** | O(h) | 递归栈深度，h 为树高（最坏 O(n)，平衡树 O(log n)） |
| **优化** | 可改为迭代后序 | 用栈模拟，避免递归深度问题 |

> 面试时写递归版本即可，代码简洁且时间复杂度已经是最优的 O(n)。

## 🎯 面试技巧

### 1. 如何向面试官解释“为什么是后序遍历”

❌ 不要这样说：
> “这是一个树形DP，所以用后序遍历。”

✅ 要这样说：
> “每个节点的最优解依赖于它的两个子节点。必须先知道儿子们能偷多少，才能决定爹偷不偷。所以用**后序遍历**——先算左右子树，再算根节点。”

### 2. 状态定义要一眼看懂

> “我对每个节点定义两个状态：偷它的时候最大收益，和不偷它的时候最大收益。这样父节点就能直接拿子节点的结果来用。”

### 3. 手写代码时的结构

```python
def dfs(node):
    if not node:
        return (0, 0)  # 空节点：怎么都是0
    
    left = dfs(node.left)   # 左子树结果
    right = dfs(node.right) # 右子树结果
    
    steal = node.val + left[1] + right[1]   # 偷当前，子节点不能偷
    skip = max(left) + max(right)           # 不偷当前，子节点随意
    
    return (steal, skip)
```

> 代码结构非常清晰，面试官一看就懂。

### 4. 画图辅助（面试桌上画个树）

```
        3
       / \
      2   3
       \   \
        3   1

从叶子往上推：
- 叶子节点3: (偷=3, 不偷=0)
- 叶子节点1: (偷=1, 不偷=0)
- 节点2: 
  偷=2+0+0=2
  不偷=max(3,0)+max(0,0)=3
  → (2, 3)
- 节点3(右):
  偷=3+0+0=3
  不偷=max(0,0)+max(1,0)=1
  → (3, 1)
- 根节点3:
  偷=3+3+1=7 ← 取max(7, max(2,3)+max(3,1)) = max(7, 3+3) = 7
  不偷=3+4=7

答案：7
```

> 边画边推，面试官会觉得你DP的底子很扎实。

### 5. 扩展追问预备

如果面试官问“如果变成 N 叉树呢？”：
> “思路完全一样，只是每个节点有多个子节点。`偷 = node.val + sum(所有子节点不偷)`，`不偷 = sum(所有子节点 max(偷, 不偷))`。时间还是 O(n)。”

如果问“空间能不能优化”：
> “可以改为迭代后序遍历，用栈来模拟递归，避免递归深度过大的问题。或者如果知道树是 AVL/红黑树这种平衡树，递归深度本来就是 O(log n)，不需要额外优化。”

| 题目 | 核心变化 | 难度 |
