## 今日算法题

### 题目：最长回文子序列

**描述**：给你一个字符串 `s`，找出其中最长的回文子序列，并返回该序列的长度。

**子序列 vs 子串**：
- **子序列**：不要求连续，只要求相对顺序不变（如 `"ace"` 是 `"abcde"` 的子序列）
- **子串**：必须连续（如 `"bcd"` 是 `"abcde"` 的子串）

**示例**：
```
输入: s = "bbbab"
输出: 4
解释: 一个可能的最长回文子序列为 "bbbb"

输入: s = "cbbd"
输出: 2
解释: 一个可能的最长回文子序列为 "bb"
```

---

### 解题思路

**核心洞察**：这道题是区间 DP 的教科书级入门。和之前线性 DP 的「从前向后递推」不同，区间 DP 的核心是**枚举区间长度**，从短到长，逐步拼出大问题的答案。

**为什么用区间 DP？**
- 一个回文串的首尾字符如果相同，去掉它们之后，中间剩下的仍然是回文串
- 这天然形成了「子区间」的结构：`s[i:j]` 的答案依赖于 `s[i+1:j-1]` 的答案
- 状态转移时，区间长度从小变大，保证子问题已计算

**状态定义**：
- `dp[i][j]`：字符串 `s` 在区间 `[i, j]`（闭区间）内的最长回文子序列长度

**状态转移方程**：
```
if s[i] == s[j]:
    dp[i][j] = dp[i+1][j-1] + 2        # 首尾相等，都选上，中间部分 +2
else:
    dp[i][j] = max(dp[i+1][j], dp[i][j-1])  # 首尾不等，舍弃其中一个，取较大值
```

**初始条件**：
- `dp[i][i] = 1`（单个字符本身就是回文，长度为 1）
- `dp[i][j] = 0`（当 `i > j` 时，空区间长度为 0，编程时可不处理）

**遍历顺序**：
> ⚠️ 关键！区间 DP 必须按「区间长度」从小到大遍历，不能按 `i` 或 `j` 单独遍历。

```
区间长度 L 从 2 到 n:
    左端点 i 从 0 到 n-L:
        右端点 j = i + L - 1
        计算 dp[i][j]
```

为什么？因为计算 `dp[i][j]` 时，需要 `dp[i+1][j-1]`、`dp[i+1][j]`、`dp[i][j-1]`，这些子区间的长度都更短，必须已经算好。

### 代码实现

#### 基础二维DP版本（面试推荐）

```python
def longestPalindromeSubseq(s: str) -> int:
    n = len(s)
    # dp[i][j] = s[i:j+1] 区间内的最长回文子序列长度
    dp = [[0] * n for _ in range(n)]
    
    # 单个字符：回文长度为 1
    for i in range(n):
        dp[i][i] = 1
    
    # 按区间长度从小到大遍历（L=2 开始，因为 L=1 已初始化）
    for L in range(2, n + 1):
        for i in range(n - L + 1):
            j = i + L - 1  # 右端点
            
            if s[i] == s[j]:
                # 首尾相同，可以同时选
                if L == 2:
                    dp[i][j] = 2  # 两个相同字符，如 "aa"
                else:
                    dp[i][j] = dp[i + 1][j - 1] + 2
            else:
                # 首尾不同，舍弃其中一个
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    
    return dp[0][n - 1]
```

> **简化写法**：`L == 2` 的特殊情况其实可以统一处理——当 `i+1 > j-1` 时（即区间只有两个字符），`dp[i+1][j-1]` 对应空区间，值为 0。如果事先把所有 `dp[i][j]`（`i > j`）视为 0，就不需要 `if L == 2` 了。

```python
def longestPalindromeSubseq(s: str) -> int:
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    
    for i in range(n):
        dp[i][i] = 1
    
    for L in range(2, n + 1):
        for i in range(n - L + 1):
            j = i + L - 1
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1] + 2
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    
    return dp[0][n - 1]
```

> 注意：当 `L = 2` 且 `s[i] == s[j]` 时，`dp[i+1][j-1]` 访问的是 `dp[i+1][i]`，即 `i > j` 的情况。由于 Python 初始化 `dp` 时所有值都是 0，所以 `dp[i+1][j-1] = 0`，结果为 `0 + 2 = 2`，正确！

#### 空间优化：一维数组（面试进阶）

> 💡 核心观察：计算 `dp[i][j]` 时，只需要「下一行」(`i+1`) 和「当前行」(`i`) 的数据。可以倒序遍历 `i`，把二维压成一维。

```python
def longestPalindromeSubseq(s: str) -> int:
    n = len(s)
    dp = [1] * n  # dp[j] 表示当前 i 下，区间 [i,j] 的答案
    
    # i 从右往左遍历
    for i in range(n - 2, -1, -1):
        prev = 0  # 保存 dp[i+1][j-1]，即左下角的值
        for j in range(i + 1, n):
            temp = dp[j]  # 先保存 dp[i+1][j]，它在被覆盖前就消失了
            if s[i] == s[j]:
                dp[j] = prev + 2
            else:
                dp[j] = max(dp[j], dp[j - 1])
            prev = temp  # 更新 prev 为下一轮的 dp[i+1][j-1]
    
    return dp[n - 1]
```

> **面试话术**：「因为计算 `dp[i][j]` 时，只需要 `dp[i+1][j-1]`（下一行左边）和 `dp[i+1][j]`（下一行正下方）、`dp[i][j-1]`（当前行左边）。所以 `i` 倒序遍历，一维数组就能满足需求。」

### 复杂度分析

| 维度 | 基础DP | 空间优化 |
|------|--------|----------|
| **时间** | O(n²) | O(n²) |
| **空间** | O(n²) | O(n) |

> 时间复杂度：共有 O(n²) 个状态，每个状态转移 O(1)，总时间 O(n²)。
> 空间优化版：利用倒序遍历，将空间降至 O(n)。

## 面试技巧

### 1. 如何向面试官解释区间 DP 的思路

**开场白**：
> "这道题我考虑用区间 DP。回文串有一个很好的性质：如果首尾字符相同，那同时去掉首尾，中间剩下的还是回文。所以大问题可以分解为更短的子区间。"

**现场画个图**（以 `"bbbab"` 为例）：

```
s = "b b b a b"
    0 1 2 3 4

计算过程（按区间长度 L 从小到大）：

L=1:  [0,0]=1 [1,1]=1 [2,2]=1 [3,3]=1 [4,4]=1

L=2:  [0,1]: s[0]==s[1]? 'b'=='b' ✓ → dp[1][0]+2 = 0+2 = 2
      [1,2]: 'b'=='b' ✓ → 2
      [2,3]: 'b'!='a' → max(dp[3][3], dp[2][2]) = max(1,1) = 1
      [3,4]: 'a'!='b' → max(1,1) = 1

L=3:  [0,2]: 'b'=='b' ✓ → dp[1][1]+2 = 1+2 = 3
      [1,3]: 'b'!='a' → max(dp[2][3]=1, dp[1][2]=2) = 2
      [2,4]: 'b'=='b' ✓ → dp[3][3]+2 = 1+2 = 3

L=4:  [0,3]: 'b'!='a' → max(dp[1][3]=2, dp[0][2]=3) = 3
      [1,4]: 'b'=='b' ✓ → dp[2][3]+2 = 1+2 = 3

L=5:  [0,4]: 'b'=='b' ✓ → dp[1][3]+2 = 2+2 = 4  ← 答案！
```

**三句话讲清**：
1. `dp[i][j]` = 区间 `[i,j]` 内的最长回文子序列长度
2. 如果 `s[i] == s[j]`，两头都能选，`dp[i][j] = dp[i+1][j-1] + 2`
3. 如果不等，舍弃其中一头，`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

### 2. 区间 DP 的通用框架

```python
# 区间 DP 万能模板（闭着眼睛都能写）
n = len(s)
dp = [[0] * n for _ in range(n)]

# 1. 初始化：长度为 1 的区间
for i in range(n):
    dp[i][i] = 初始值

# 2. 按区间长度从小到大枚举
for L in range(2, n + 1):           # L = 区间长度
    for i in range(n - L + 1):      # i = 左端点
        j = i + L - 1                # j = 右端点
        # 3. 状态转移（根据题目写具体逻辑）
        dp[i][j] = ...

# 4. 答案
return dp[0][n - 1]
```

> **背下这个框架**，所有区间 DP 题目都是这个结构：初始化长度为 1 → 枚举区间长度 → 枚举左端点 → 计算右端点 → 状态转移。

### 3. 常见追问及应对

| 追问 | 应对策略 |
|------|---------|
| "区间 DP 和线性 DP 的本质区别是什么？" | 答：线性 DP 的状态通常是一维的（`dp[i]` 表示前缀），而区间 DP 的状态是二维的（`dp[i][j]` 表示子区间）。线性 DP 从前向后递推，区间 DP 按区间长度从小到大递推。 |
| "时间复杂度为什么是 O(n²)？" | 答：状态数是 O(n²) 个区间，每个状态的转移是 O(1)，总时间 O(n²)。 |
| "空间能优化到 O(n) 吗？" | 答：可以。因为计算 `dp[i][j]` 只依赖下一行和当前行的数据，`i` 倒序遍历即可用一维数组。 |
| "这道题和 LCS 有什么关系？" | 答：LPS(s) = LCS(s, reverse(s))。回文串正读反读相同，所以原串和反转串的公共子序列就是回文子序列。 |
| "如果要求返回具体的回文子序列，而不是长度呢？" | 答：可以。在 DP 过程中记录选择路径（从哪个方向转移来的），最后从 `dp[0][n-1]` 回溯重构即可。 |
| "子串和子序列的区别是什么？" | 答：子序列不要求连续，子串要求连续。最长回文子串要用中心扩展法或 Manacher 算法，和这道题完全不同。 |

- [ ] 先问清楚是「子序列」还是「子串」（一字之差，解法天差地别）

- [ ] 强调遍历顺序：必须按区间长度从小到大，不能按 `i` 或 `j` 单独遍历
- [ ] 主动提及与 LCS 的联系（展示知识广度）
- [ ] 如果面试官追问，给出空间优化版本（倒序遍历 + 一维数组）
- [ ] 区分「最长回文子序列」（区间 DP）和「最长回文子串」（中心扩展 / Manacher）

### 5. 易错点提醒

⚠️ **遍历顺序**：区间 DP 最常见的错误就是遍历顺序错了。必须先枚举区间长度 `L`，再枚举左端点 `i`。如果按 `i` 从 0 到 n，`j` 从 `i` 到 n 遍历，子问题可能还没算好。

⚠️ **L=2 的边界**：两个相同字符 `"aa"`，`dp[i][j] = dp[i+1][j-1] + 2`。`dp[i+1][j-1]` 是空区间，值为 0，所以结果是 2。如果语言/实现没有默认 0，需要特判。

⚠️ **空间优化的 `prev` 变量**：一维优化时，`prev` 保存的是「左下角」`dp[i+1][j-1]` 的值，要在 `dp[j]` 被覆盖前及时保存。这个细节容易写错。

⚠️ **和最长回文子串的混淆**：
- 最长回文**子序列** → 不连续 → 区间 DP
- 最长回文**子串** → 连续 → 中心扩展 / Manacher
