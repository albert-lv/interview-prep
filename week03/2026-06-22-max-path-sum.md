## 今日算法题

### 题目描述

给定一个**非空**二叉树，返回其最大路径和。

路径被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。该路径**至少包含一个**节点，且不一定经过根节点。

**示例 1:**
```
输入: root = [1,2,3]
       1
      / \
     2   3
输出: 6
解释: 最优路径是 2 -> 1 -> 3，路径和为 2 + 1 + 3 = 6
```

**示例 2:**
```
输入: root = [-10,9,20,null,null,15,7]
       -10
       / \
      9  20
        /  \
       15   7
输出: 42
解释: 最优路径是 15 -> 20 -> 7，路径和为 15 + 20 + 7 = 42
```

**约束条件:**
- 树中节点数目范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

---

### 解题思路

这道题是**树形DP**的经典模板题，核心思想是：

> 对于每个节点，我们计算"以该节点为端点的最大路径和"，同时用全局变量追踪"经过该节点的最大路径和"。

**关键洞察：**

1. **以当前节点为端点的最大路径和**（返回给父节点用的）：
   - 只能选左子树或右子树中的一个（不能分叉，因为路径是线性的）
   - 也可以选择不选（如果子树贡献为负）
   - 公式：`max(0, max(left, right)) + node.val`

2. **经过当前节点的最大路径和**（用来更新全局答案的）：
   - 可以左子树 + 当前节点 + 右子树（呈"倒V"型）
   - 公式：`max(0, left) + max(0, right) + node.val`

**为什么这是树形DP？**
- 子问题定义在每个节点上
- 子问题的解依赖于左右子树的解
- 通过后序遍历（左右根）自底向上计算

---

### 代码实现

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.max_sum = float('-inf')
        
        def dfs(node):
            if not node:
                return 0
            
            # 后序遍历：先计算左右子树
            # 如果子树贡献为负，就不选（取0）
            left_gain = max(dfs(node.left), 0)
            right_gain = max(dfs(node.right), 0)
            
            # 以当前节点为"拐点"的路径和（左-根-右）
            price_newpath = left_gain + node.val + right_gain
            
            # 更新全局最大值
            self.max_sum = max(self.max_sum, price_newpath)
            
            # 返回"以当前节点为端点"的最大路径和（给父节点用的）
            # 注意：只能选一边，不能两边都选（否则路径分叉了）
            return node.val + max(left_gain, right_gain)
        
        dfs(root)
        return self.max_sum
```

---

### 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **时间复杂度** | O(N) | 每个节点只访问一次 |
| **空间复杂度** | O(H) | H为树的高度，递归栈空间。最坏O(N)（退化为链表），平均O(log N) |

---

### 易错点自查清单

- [ ] **负数处理**：`max(子树贡献, 0)` —— 负数子树果断放弃
- [ ] **返回值 vs 全局值**：返回给父节点的是"单边最大值"，更新全局的是"两边之和+根"
- [ ] **初始值**：`max_sum` 初始化为 `-inf`，不要设为0（可能全是负数）
- [ ] **不要两边都返回**：返回时只能 `max(left, right)`，不能 `left + right`

## 面试技巧

### 1. 如何向面试官解释这道题

**30秒版本：**
> "这道题用树形DP + 后序遍历。每个节点我们需要两个信息：① 以它为端点的最大路径和（返回给父节点）② 经过它的最大路径和（更新全局答案）。关键是不能分叉，所以返回时只能选左右一边。"

**画图辅助：**
```
        -10
        / \
       9  20
         /  \
        15   7

对节点20：
  - 左子树贡献：15（>0，要）
  - 右子树贡献：7（>0，要）
  - 经过20的路径和：15 + 20 + 7 = 42 ✅ 全局最大值
  - 返回给父节点的：20 + max(15,7) = 35（只能选一边！）
```

### 2. 面试官可能的追问

| 追问 | 应对策略 |
|------|----------|
| "如果路径必须走根节点？" | 把递归逻辑改一下，但复杂度不变 |
| "如果要求返回路径本身？" | 维护一个 `parent` 指针或记录路径节点，空间变O(N) |
| "改成N叉树呢？" | 从"左右两边"变成"所有子节点中选最大的两个"或"选最大的一个" |
| "空间复杂度能优化吗？" | 可以Morris遍历做到O(1)，但代码复杂，面试一般不苛求 |

### 3. 代码面试时的表达技巧

**边说边写模板：**
```
"首先，这是一个后序遍历的问题，因为当前节点的结果
 需要左右子树的信息。"

"我定义一个辅助函数，返回以当前节点为端点的最大路径和。"

"对于每个节点，先递归获取左右子树的贡献，
 如果贡献是负的，就不选，取0。"

"然后计算经过当前节点的路径和，更新全局最大值。"

"最后返回给父节点的时候，注意只能选一边，
 因为路径不能分叉。"
```
