## 今日算法题：二叉树的直径

**题目编号：** LeetCode 543
**难度：** 中等 ⭐⭐
**标签：** 树形DP、DFS、递归

---

### 题目描述

给定一棵二叉树，你需要计算它的**直径长度**。

一棵二叉树的**直径**是任意两个节点之间路径长度的**最大值**。这条路径可能经过也可能不经过根节点。

路径的长度等于路径中**边的数量**（不是节点数）。

**示例 1：**
```
    1
   / \
  2   3
 / \
4   5
```
输出：`3`
解释：路径 `[4,2,1,3]` 或 `[5,2,1,3]`，边数为 3。

**示例 2：**
```
    1
   /
  2
 /
3
```
输出：`2`

---

### 思路解析

这道题和昨天的「二叉树中的最大路径和」是**亲兄弟**，核心思想完全一致：

> 对于每个节点，经过它的最长路径 = 左子树最大深度 + 右子树最大深度

#### 关键洞察 🔍

1. **"直径"的定义**：任意两个节点之间的最长路径。这等价于：找到某个节点，使得 `左子树深度 + 右子树深度` 最大。

2. **为什么是深度相加？** 因为对于一条经过当前节点的路径，它必须从左子树的某个叶子出发，经过当前节点，到达右子树的某个叶子。这条路径的边数 = 左子树深度 + 右子树深度。

3. **树形DP三板斧**：
   - 后序遍历：先处理子节点，再处理当前节点
   - 返回值：当前子树的最大深度（供父节点使用）
   - 全局更新：用返回值计算经过当前节点的路径，更新全局答案

#### 与「最大路径和」的区别

| | 二叉树直径 | 二叉树最大路径和 |
|---|---|---|
| 目标 | 边数最大 | 节点值和最大 |
| 经过某节点的值 | 左深度 + 右深度 | 左最大和 + 右最大和 + 节点值 |
| 返回值 | 子树最大深度 | 子树最大路径和（至少包含当前节点）|
| 空子树处理 | 深度为0 | 路径和为0（可能为负时不取）|

理解了最大路径和，这道题就是**换皮**——思维模型完全一样。

### 代码实现

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: TreeNode) -> int:
        self.diameter = 0
        
        def dfs(node):
            if not node:
                return 0
            
            # 后序遍历：先递归处理左右子树
            left_depth = dfs(node.left)
            right_depth = dfs(node.right)
            
            # 经过当前节点的路径长度 = 左深度 + 右深度
            # 更新全局直径
            self.diameter = max(self.diameter, left_depth + right_depth)
            
            # 返回以当前节点为根的最大深度（供父节点使用）
            return max(left_depth, right_depth) + 1
        
        dfs(root)
        return self.diameter
```

#### 代码关键点

1. **`dfs(node)` 返回什么？** — 以 `node` 为根的子树的最大深度（从 `node` 往下走的最大边数）
2. **为什么返回 `max(left, right) + 1`？** — 因为深度只取一条分支，不能分叉
3. **全局答案何时更新？** — 在递归回溯时，计算 `left + right`，这是经过当前节点的路径
4. **边的数量 vs 节点数量：** 深度定义为边的数量，所以叶子节点返回0，每上一层+1

### 复杂度分析

| 指标 | 复杂度 | 说明 |
|---|---|---|
| **时间** | O(N) | 每个节点只访问一次 |
| **空间** | O(H) | 递归栈深度，H为树高，最坏O(N)（退化成链表）|

### 举一反三 🌟

如果面试官追问，可以主动扩展：

**Q: 如果是N叉树，直径怎么求？**  
A: 找子树中两个最大的深度相加，原理相同。需要记录每个子节点的深度，取top2。

**Q: 直径一定经过根节点吗？**  
A: 不一定！这就是为什么要遍历每个节点计算 `left_depth + right_depth`，全局取最大值。叶子节点单独不会形成路径（长度=0），但路径可能完全在某子树中。

**Q: 如果要返回具体路径呢？**  
A: 记录取得最大值时的节点，再分别找左右子树的最深叶子路径，拼接起来。面试中如果提到这点，很加分。

## 面试技巧：树形DP的通用模板

### 💡 三板斧公式

树形DP题，尤其是二叉树上的最值问题，基本都可以套用以下模板：

```python
def dfs(node):
    if not node:
        return 基础值  # 空节点返回什么取决于题意
    
    left = dfs(node.left)   # 先递归
    right = dfs(node.right)
    
    # 1. 用子树结果计算"经过当前节点的答案"
    #    update global_answer
    
    # 2. 返回"以当前节点为根的某种信息"（供父节点使用）
    return 某种聚合值
```

**常见返回值类型：**
- 最大/最小深度 → 本题、最大路径和
- 最大/最小路径和 → 最大路径和
- 子树是否满足某条件 → 平衡二叉树、BST验证
- 子树的大小/节点数 → 各种统计问题

### 🗣 面试话术：如何"现场推导"这个模板

如果面试时没做过这题，可以这样边想边说：

> "我先用后序遍历，因为子树的信息对父节点有用。
> 对于每个节点，我需要知道什么？
> —— 我需要知道左子树和右子树各自的最大深度。
> 然后经过当前节点的最长路径就是两者相加。
> 但返回给父节点时，只能选一条分支，因为路径不能分叉。
> 所以返回 `max(left, right) + 1`。
> 同时用一个全局变量记录最大直径。"

这种"自言自语"式的推导，面试官会很欣赏——它展示了你**结构化思考**的能力。

### 🎯 树形DP高频题分类

| 类型 | 代表题 | 核心思路 |
|---|---|---|
| 最值路径 | 最大路径和、直径 | 后序 + 全局更新 |
| 选择型 | 打家劫舍 III | 选/不选当前节点，分状态 |
| 验证型 | 平衡二叉树、BST | 后序返回子树信息 |
| 树转序列 | 序列化、LCA | 前序/中序性质 |
| 树上区间 | 预测赢家（博弈） | 区间DP在树上的变体 |

### ⚠️ 常见翻车点

1. **返回值和全局答案混淆**  
   返回值是"给父节点用的"（单边深度），全局答案是"经过当前节点的完整路径"。这俩不一样！

2. **边的数量 vs 节点数量**  
   直径是边数，两个节点之间如果有2条边，直径是2。如果算节点数会多1。面试时问清楚面试官的定义。

3. **空节点返回值的设定**  
   深度：空节点返回0；路径和：根据题意可能是0或-inf。看具体场景。

4. **只考虑经过根节点的路径**  
   新手容易写成只算 `root` 的左右深度，忘记递归过程中每个节点都可能是"根"。这就是为什么需要全局变量。
