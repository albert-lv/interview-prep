# Day 16: 戳气球 — 区间 DP 经典 trick

## 📝 题目描述

有 `n` 个气球，编号为 `0` 到 `n-1`，每个气球上有一个数字，由数组 `nums` 表示。

现在你戳破所有的气球。每戳破一个气球 `i`，你可以获得 `nums[left] * nums[i] * nums[right]` 个硬币，其中 `left` 和 `right` 是 `i` 相邻的两个**未被戳破**的气球。

求你能获得的最大硬币数。

**注意**：你可以假设 `nums[-1] = nums[n] = 1`（边界外视为 1，但边界本身不能戳破）。

**示例**:
```
输入: nums = [3,1,5,8]
输出: 167
解释: 
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 15 + 120 + 24 + 8 = 167
```

---

## 💡 核心思路

戳气球这题最反直觉的地方：**正向思考（先戳哪个）会爆炸，逆向思考（哪个最后戳）就通了。**

### 为什么正向不行？

如果你先戳气球 `i`，左右两边的气球就**相邻了**，整个数组结构变了。子问题不是原问题的缩小版，无法直接套 DP。

### 逆向思维：谁最后戳？

换个角度：**假设区间 `[i, j]` 内最后戳破的气球是 `k`**。那么：
- 戳 `k` 时，左边剩 `i-1`，右边剩 `j+1`（这两个还没被戳）
- 收益 = `nums[i-1] * nums[k] * nums[j+1]`
- 再加上 `[i, k-1]` 和 `[k+1, j]` 两个子区间的最优解

> **关键 insight**：最后戳 `k` 时，左右边界是固定的！子问题彻底独立了。

### 状态定义

```
dp[i][j] = 戳破区间 (i, j) 内所有气球（不包括边界 i 和 j）能获得的最大硬币数
```

注意开区间：`(i, j)` 表示 `i+1, i+2, ..., j-1` 这些气球。

边界 `i` 和 `j` 本身**不戳**，只用来计算收益。

### 状态转移

```
// 枚举 (i, j) 区间内最后戳破的气球 k
for k in range(i+1, j):
    dp[i][j] = max(dp[i][j], 
                   dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j])
```

> 用大白话：最后戳 `k` 时，左边区间 `(i, k)` 先搞定，右边区间 `(k, j)` 先搞定，然后戳 `k` 拿 `nums[i]*nums[k]*nums[j]`。

### 遍历顺序：区间长度从小到大

因为 `dp[i][j]` 依赖更短的区间 `dp[i][k]` 和 `dp[k][j]`（其中 `i < k < j`），所以按**区间长度**从小到大填表。

```
长度 2: dp[0][1], dp[1][2], ...  (区间内没有气球，都是0)
长度 3: dp[0][2], dp[1][3], ...  (区间内有1个气球)
长度 4: dp[0][3], dp[1][4], ...  (区间内有2个气球)
...
```

## 🖥️ 代码实现

```python
from typing import List

class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        # 首尾添加虚拟气球 1，方便处理边界
        nums = [1] + nums + [1]
        n = len(nums)
        
        # dp[i][j] = 开区间 (i, j) 内能获得的最大硬币数
        dp = [[0] * n for _ in range(n)]
        
        # 按区间长度从小到大枚举（长度至少为2才有意义）
        for length in range(2, n):  # length = j - i
            for i in range(n - length):
                j = i + length
                # 枚举 (i, j) 内最后一个戳破的气球 k
                for k in range(i + 1, j):
                    # 左边 (i, k) + 右边 (k, j) + 最后戳 k 的收益
                    dp[i][j] = max(
                        dp[i][j],
                        dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j]
                    )
        
        # 整个数组对应开区间 (0, n-1)
        return dp[0][n - 1]


# 验证
sol = Solution()
print(sol.maxCoins([3, 1, 5, 8]))  # 输出: 167
print(sol.maxCoins([1, 5]))        # 输出: 10
```

## ⏱️ 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **时间** | O(n³) | 区间 O(n²) × 枚举 k O(n) |
| **空间** | O(n²) | dp 数组大小 |
| **优化** | 可压至 O(n²) | 时间已经是该题标准解法，面试写这个即可 |

> 面试时写这个 O(n³) 版本就够了。如果面试官追问优化，可以提到「分治 + 记忆化搜索」是等价写法，但时间复杂度一样。

## 🎯 面试技巧

### 1. 开场白：先讲"为什么这题难"

> "这题如果直接想'先戳哪个'，会发现戳完一个之后数组结构变了，子问题和原问题不是同一个结构。所以换个思路——**假设 k 是最后戳的**，这样左右两边就独立了，是典型的区间 DP。"

这句话一出来，面试官就知道你抓住核心了。

### 2. 逆向思维是亮点，要强调

> "区间 DP 里有个经典 trick：正向不好做时，尝试**固定最后一个操作的对象**。这题就是固定最后戳的气球，矩阵链乘法也是固定最后乘的矩阵。"

### 3. 状态定义要说清楚"开区间"

> "我定义 `dp[i][j]` 为**开区间** `(i, j)` 内所有气球戳完的最大收益。边界 `i` 和 `j` 本身不戳，只是用来算钱的。这样最后戳 `k` 时，收益就是 `nums[i] * nums[k] * nums[j]`，非常干净。"

### 4. 边界处理的优雅方式

> "原数组首尾加两个虚拟气球 1，这样 `nums[-1]` 和 `nums[n]` 的问题就自然消解了。最后答案就是 `dp[0][n-1]`。"

### 5. 手写代码时的结构

```python
# 1. 加边界
nums = [1] + nums + [1]

# 2. 初始化 dp
n = len(nums)
dp = [[0] * n for _ in range(n)]

# 3. 按长度枚举区间
for length in range(2, n):
    for i in range(n - length):
        j = i + length
        for k in range(i + 1, j):
            dp[i][j] = max(dp[i][j], 
                           dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])

# 4. 答案
return dp[0][n-1]
```

> 结构非常清晰：加边界 → 建表 → 三层循环填表 → 返回答案。

### 6. 画图辅助（面试桌上画个小例子）

```
nums = [1, 3, 1, 5, 8, 1]  (加了边界)
         0  1  2  3  4  5

求 dp[0][5]：
  枚举最后戳 k=1: dp[0][1] + dp[1][5] + 1*3*1 = 0 + ? + 3
  枚举最后戳 k=2: dp[0][2] + dp[2][5] + 1*1*1 = ? + ? + 1
  枚举最后戳 k=3: dp[0][3] + dp[3][5] + 1*5*1 = ? + ? + 5
  枚举最后戳 k=4: dp[0][4] + dp[4][5] + 1*8*1 = ? + ? + 8

先算短区间：
  dp[0][2]: k=1 → 1*3*1 = 3
  dp[1][3]: k=2 → 3*1*5 = 15
  dp[2][4]: k=3 → 1*5*8 = 40
  dp[3][5]: k=4 → 5*8*1 = 40
  ...

层层递推，最终 dp[0][5] = 167
```

> 边画边解释区间怎么展开，面试官会觉得你的 DP 功底很扎实。

### 7. 扩展追问预备

如果面试官问"时间能不能优化"：
> "这题最优解就是 O(n³)，已经证明过了。如果 `n` 很小（比如 ≤ 50），这个复杂度完全可接受。如果非要优化，可以研究一下四边形不等式优化，把枚举 k 的过程剪枝，但实现复杂，面试不建议写。"

如果问"和矩阵链乘法的关系"：
> "本质上是同一类问题。矩阵链乘法是固定最后乘的矩阵，把链分成左右两段；戳气球是固定最后戳的气球，把区间分成左右两块。都是'逆向思考，固定最后一个操作'的区间 DP 模板。"

## 🔗 举一反三

| 题目 | 核心变化 | 难度 |
|------|----------|------|
| **矩阵链乘法** | 固定最后乘的矩阵，算最少乘法次数 | ⭐⭐⭐⭐ |
| **移除盒子** | 有相同颜色，连续移除有加分 | ⭐⭐⭐⭐⭐ |
| **预测赢家** | 两人轮流从两端取数，先手是否必胜 | ⭐⭐⭐⭐ |
| **石子的最大得分** | 区间合并，每次合并不再是 sum 而是乘积 | ⭐⭐⭐⭐ |
| **Burst Balloons 进阶** | 带限制条件，某些气球不能最后戳 | ⭐⭐⭐⭐⭐ |

> 区间 DP 的 trick 总结：**正向难做就逆向，固定最后一个操作对象，子问题自动独立**。矩阵链乘法、戳气球、预测赢家都遵循这个套路。
