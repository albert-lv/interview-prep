## 今日算法题

### 题目描述

给你一个整数数组 `nums`。玩家1和玩家2轮流从数组的**两端**取数（每次只能取最左边或最右边的一个数），取走的数累加到自己的得分上。两人都采用最优策略，判断**玩家1**是否能成为赢家（得分 >= 玩家2）。

假设数组长度总是偶数，且两人总分不同（无平局）。

**示例 1:**
```
输入: nums = [1,5,2]
输出: false
解释: 玩家1先取：
  - 若取1，数组剩[5,2]，玩家2取5，玩家1取2，得分 1+2=3 < 5
  - 若取2，数组剩[1,5]，玩家2取5，玩家1取1，得分 2+1=3 < 5
  玩家1无法获胜。
```

**示例 2:**
```
输入: nums = [1,5,233,7]
输出: true
解释: 玩家1先取1，数组剩[5,233,7]，玩家2只能取5或7，
  无论玩家2取哪个，玩家1下一轮都能取到233，稳赢。
```

**约束条件:**
- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 10^7`

---

### 解题思路

这道题是**区间DP + 博弈论**的经典组合。核心难点在于：**「最优策略」意味着双方都会让对手最小化收益，同时最大化自己的收益。**

**状态设计：**

`dp[i][j]` = 在数组 `nums[i...j]` 范围内，**当前行动玩家**能获得的最大**净胜分**（当前玩家得分 - 对手得分）

> 注意：不是「当前玩家能获得的最大分数」，而是「净胜分」。这个设计非常关键，因为博弈中你不仅要让自己拿得多，还要让对手拿得少。

**状态转移：**

当前玩家有两个选择：
1. **取左边** `nums[i]`：然后轮到对手在 `nums[i+1...j]` 行动。对手也会采用最优策略，获得 `dp[i+1][j]` 的净胜分。那么当前玩家的净胜分 = `nums[i] - dp[i+1][j]`
2. **取右边** `nums[j]`：同理，当前玩家的净胜分 = `nums[j] - dp[i][j-1]`

所以递推公式：
```
dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])
```

> 为什么用减法？因为 `dp[i+1][j]` 表示的是「对手作为当前玩家」时的净胜分（对手得分 - 我方得分）。所以当前玩家的最终净胜分 = 我方拿走的 - 对手后续的净胜分。

**边界条件：**
- `dp[i][i] = nums[i]`（只剩一个数，当前玩家拿走，净胜分就是这个数）

**最终答案：**
- 如果 `dp[0][n-1] >= 0`，玩家1能赢（净胜分非负）
- 否则不能赢

**为什么这是区间DP？**
- 子问题定义在一个区间 `[i,j]` 上
- 小区间的结果推导出大区间
- 填表顺序：按区间长度从小到大

---

### 代码实现

```python
class Solution:
    def predictTheWinner(self, nums: List[int]) -> bool:
        n = len(nums)
        
        # dp[i][j] = 在nums[i..j]范围内，当前玩家能获得的最大净胜分
        dp = [[0] * n for _ in range(n)]
        
        # 边界：区间长度为1时，只能取nums[i]
        for i in range(n):
            dp[i][i] = nums[i]
        
        # 按区间长度从小到大填表
        for length in range(2, n + 1):  # 区间长度从2到n
            for i in range(n - length + 1):
                j = i + length - 1
                # 取左边：拿到nums[i]，然后对手在[i+1,j]的净胜分是dp[i+1][j]
                # 当前净胜分 = nums[i] - 对手净胜分
                take_left = nums[i] - dp[i + 1][j]
                # 取右边
                take_right = nums[j] - dp[i][j - 1]
                dp[i][j] = max(take_left, take_right)
        
        # 初始时整个数组，玩家1先行动
        return dp[0][n - 1] >= 0
```

**空间优化版本（滚动数组）：**

```python
class Solution:
    def predictTheWinner(self, nums: List[int]) -> bool:
        n = len(nums)
        # 只需要上一行（i+1）和当前行（i）
        dp = [0] * n
        
        for i in range(n - 1, -1, -1):
            dp[i] = nums[i]  # dp[i][i] = nums[i]
            for j in range(i + 1, n):
                dp[j] = max(nums[i] - dp[j], nums[j] - dp[j - 1])
                # 注意：dp[j] 在更新前存储的是 dp[i+1][j]
                #       dp[j-1] 在本轮已经更新，存储的是 dp[i][j-1]
        
        return dp[n - 1] >= 0
```

### 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **时间复杂度** | O(N²) | 枚举所有区间，共 N²/2 个状态 |
| **空间复杂度** | O(N²) | 二维DP数组，优化后可到 O(N) |

### 易错点自查清单

- [ ] **状态定义**：`dp[i][j]` 是**净胜分**，不是「当前玩家能拿的最大分数」
- [ ] **为什么是减法**：`nums[i] - dp[i+1][j]`，不是 `nums[i] + dp[i+1][j]` —— 因为接下来对手行动，对手的净胜分就是你的负净胜分
- [ ] **填表顺序**：按区间长度从小到大，或者 i 从大到小（逆序）
- [ ] **边界条件**：`dp[i][i] = nums[i]`，不是0
- [ ] **空间优化时注意**：`dp[j]` 在更新前存的是 `dp[i+1][j]`（上一行），`dp[j-1]` 已更新为 `dp[i][j-1]`（当前行）

## 面试技巧

### 1. 如何向面试官解释这道题

**30秒版本：**
> "这是区间DP + 博弈论。定义 `dp[i][j]` 为在区间 `nums[i..j]` 内当前玩家的最大净胜分。当前玩家可以取左边或右边，取完后对手变成「当前玩家」继续游戏。所以递推是 `max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`，用减法是因为 dp 存的是净胜分。"

**博弈论直觉：**
> "可以把问题看成：当前玩家选择一个数，然后让对手面对一个子问题。对手的子问题最优解，对当前玩家来说就是最差情况。所以要减去对手的净胜分。"

**画图辅助：**
```
nums = [1, 5, 233, 7]

玩家1取1，数组剩[5,233,7]
  玩家2（作为当前玩家）面对[5,233,7]
  玩家2的净胜分 = dp[1][3]
  
  所以玩家1的整体净胜分 = 1 - dp[1][3]
  
  如果 dp[1][3] = -225（意味着玩家2净胜-225，即玩家1赢225）
  那么玩家1的净胜分 = 1 - (-225) = 226 ✓
```

### 2. 面试官可能的追问

| 追问 | 应对策略 |
|------|----------|
| "为什么不用『当前玩家最大得分』做状态？" | 因为博弈论中只关心相对优势。净胜分更简洁，且状态转移只需要减法。如果存最大得分，需要同时追踪对手得分，状态复杂。 |
| "如果数组长度是奇数呢？" | 题目限制了偶数，但奇数也能做。奇数时先手不一定有优势，但 DP 逻辑不变。 |
| "空间优化怎么做的？" | 因为 `dp[i][j]` 只依赖 `dp[i+1][j]`（下一行）和 `dp[i][j-1]`（当前行左边），所以一维数组滚动即可。 |
| "能不能用递归+记忆化？" | 可以，思路一样。`dfs(i,j)` 返回当前玩家在 `nums[i..j]` 的净胜分。时间复杂度相同，但可能面临栈深度问题。 |
| "如果两个人不采用最优策略呢？" | 那就不是 DP 问题了，可能需要蒙特卡洛模拟或博弈树搜索。但面试中这种追问很少，主要是考察最优策略的理解。 |
