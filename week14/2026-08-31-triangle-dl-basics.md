## 一、今日算法题：三角形最小路径和

### 题目

给定一个三角形 `triangle`，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上。**相邻的结点** 在这里指的是 `下标` 与 `上一层结点下标` 相同或者等于 `上一层结点下标 + 1` 的两个结点。

也就是说，如果正位于当前行的下标 `i`，那么下一步可以移动到下一行的下标 `i` 或 `i + 1`。

**示例：**
```
输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出：11
解释：自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。

输入：triangle = [[-10]]
输出：-10
```

**约束：**
- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`
- `-10^4 <= triangle[i][j] <= 10^4`

---

### 思路

**核心洞察**：自顶向下还是自底向上？这道题自底向上 DP 更简洁。

如果从顶部往下走，每个位置都要考虑「从哪来」，边界情况多（每行第一个和最后一个只能从一个方向来）。

但如果**从底部往上推**，每个位置只需要考虑「下面两个选谁」：

```
dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])
```

这和神经网络里的**反向传播**有异曲同工之妙——信息从输出层往输入层流，逐层计算梯度。

**为什么选这道题？**
- 三角形的「层」结构 ≈ 神经网络的「层」结构
- 自底向上的 DP ≈ 反向传播（Backpropagation）
- 每个节点依赖下一层两个节点 ≈ 计算图中节点的局部梯度依赖下游梯度

**面试时怎么展开？**
> "这道题我用自底向上的动态规划，和训练神经网络时的反向传播思路很像——都是从输出往输入推，每个位置只需要关心下一层的结果，不用管全局路径。"

---

### 代码实现

#### Python 解法（自底向上 DP，O(n²) 空间）

```python
from typing import List

class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        n = len(triangle)
        # dp[i][j] 表示从 (i,j) 出发到最底层的最小路径和
        dp = [[0] * len(row) for row in triangle]
        
        # 初始化：最底层就是它自己
        for j in range(len(triangle[-1])):
            dp[-1][j] = triangle[-1][j]
        
        # 自底向上递推
        for i in range(n - 2, -1, -1):
            for j in range(len(triangle[i])):
                dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])
        
        return dp[0][0]
```

#### Python 解法（空间优化，O(n) 空间）

```python
from typing import List

class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        """
        空间优化：只用一维数组，从底向上原地更新
        dp[j] 表示当前层第 j 个位置到底层的最小路径和
        """
        n = len(triangle)
        # 用最后一行初始化 dp
        dp = triangle[-1][:]
        
        for i in range(n - 2, -1, -1):
            for j in range(len(triangle[i])):
                # 覆盖更新：dp[j] = 当前值 + min(正下方, 右下方)
                dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
        
        return dp[0]
```

#### Go 解法（空间优化 O(n)）

```go
package main

import "fmt"

func minimumTotal(triangle [][]int) int {
	n := len(triangle)
	if n == 0 {
		return 0
	}
	
	// 用最后一行初始化 dp
	dp := make([]int, len(triangle[n-1]))
	copy(dp, triangle[n-1])
	
	// 自底向上
	for i := n - 2; i >= 0; i-- {
		for j := 0; j < len(triangle[i]); j++ {
			if dp[j] < dp[j+1] {
				dp[j] = triangle[i][j] + dp[j]
			} else {
				dp[j] = triangle[i][j] + dp[j+1]
			}
		}
	}
	
	return dp[0]
}

func main() {
	triangle := [][]int{
		{2},
		{3, 4},
		{6, 5, 7},
		{4, 1, 8, 3},
	}
	fmt.Println(minimumTotal(triangle)) // 输出: 11
}
```

### 面试官 Follow-up

**Q：如果三角形很大（10⁵ 行），还能优化吗？**
> 时间 O(n²) 是下限，因为每个节点都要访问一次。空间已经 O(n) 最优。如果还要优化，可以考虑并行计算——每一层的节点之间没有依赖，可以并行求 min。

**Q：这和神经网络有什么关系？**
> 三角形的层结构就像神经网络的前向传播：输入从顶层进入，每层做变换，信息逐层往下传。而自底向上的 DP 就像反向传播：从损失函数（最底层）出发，逐层往回算每个参数对最终损失的贡献。

**Q：如果改成「最大路径和」，代码要改哪里？**
> 把 `min` 改成 `max` 就行。这种题的变体很常考，掌握一个就能举一反三。

## 二、面试技巧：深度学习与神经网络核心原理

### 🎯 核心速查卡

#### 1. 从感知机到多层神经网络

```
感知机（Perceptron，1958）
    ↓
多层感知机 MLP（1986，反向传播）
    ↓
深度神经网络 DNN（2012，AlexNet 引爆）
    ↓
CNN / RNN / Transformer（各司其职）
```

**感知机**：`y = σ(w·x + b)`，一个线性分类器。

**为什么需要多层？**
> 单层感知机只能解决线性可分问题（如 XOR 都搞不定）。多层 + 非线性激活 = **万能近似定理**：一个足够宽的浅层网络可以逼近任意连续函数。

> 💬 **面试官**："为什么神经网络要加激活函数？"
>
> 🎯 **你**："没有激活函数，不管多少层都等价于一层线性变换——`W₃(W₂(W₁x)) = W'x`，深层就没意义了。激活函数引入非线性，让网络能拟合复杂决策边界。"

---

#### 2. 激活函数：神经网络的「非线性开关」

| 激活函数 | 公式 | 导数 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|---|---|
| **Sigmoid** | 1/(1+e⁻ˣ) | σ(1-σ) | 输出在 (0,1)，可解释概率 | ❌ 两端饱和，梯度消失 | 二分类输出层 |
| **Tanh** | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 1-tanh² | 零中心化，比 Sigmoid 梯度强 | ❌ 仍有饱和问题 | 隐藏层（较少用了） |
| **ReLU** | max(0, x) | x>0 ? 1 : 0 | ✅ 计算快、缓解梯度消失 | ❌ 负值永远死亡（Dead ReLU） | **隐藏层默认首选** |
| **Leaky ReLU** | max(αx, x) | x>0 ? 1 : α | 解决 Dead ReLU | α 是超参 | 替代 ReLU |
| **GELU** | x·Φ(x) | 复杂 | ✅ 平滑、Transformer 标配 | 计算稍贵 | BERT/GPT 等 |
| **Softmax** | eˣⁱ/Σeˣʲ | 复杂 | 多分类概率归一化 | — | 多分类输出层 |

**激活函数选择决策树**：
```
隐藏层？
├── 是 → Transformer？→ 是 → GELU/SiLU
│       └── 否 → ReLU（默认）/ Leaky ReLU（怕死神经元）
└── 否（输出层）→ 二分类？→ 是 → Sigmoid
                └── 否 → 多分类？→ 是 → Softmax
                            └── 否 → 回归 → 无激活 / 线性
```

> 💬 **面试官**："ReLU 为什么比 Sigmoid 好？"
>
> 🎯 **你**："三点：① 计算简单，没有指数运算；② 正区间梯度恒为 1，不会饱和，缓解梯度消失；③ 稀疏激活——一部分神经元不激活，自带正则化效果。缺点是负区间梯度为 0 导致神经元死亡，所以后面出了 Leaky ReLU 和 GELU。"

---

#### 3. 反向传播：链式法则的自动化

**核心思想**：计算图 + 链式法则。

```
损失 L 对参数 w 的梯度 = ∂L/∂w
                          = ∂L/∂output · ∂output/∂w
                          
多层时链式展开：
∂L/∂w₁ = ∂L/∂y₃ · ∂y₃/∂y₂ · ∂y₂/∂y₁ · ∂y₁/∂w₁
         ↑输出层梯度   ↑逐层往回传    ↑局部梯度
```

**面试一句话解释**：
> "反向传播就是计算图上的链式法则自动求导。前向传播算输出，反向传播从损失往回传梯度，每个节点只需要算自己的局部梯度，然后乘以上游传来的梯度——这也是它能高效的原因。"

**计算图示例**：
```
输入 x ──┐
        ├──→ ⊗ ──→ + ──→ y = wx + b ──→ σ ──→ ŷ
参数 w ──┘     ↑      ↑
参数 b ────────┘      
                      损失 L = (ŷ - y)²
```

---

#### 4. 损失函数：模型学习的「方向标」

| 损失函数 | 公式 | 适用场景 | 特点 |
|---|---|---|---|
| **MSE** | 1/n Σ(ŷ-y)² | 回归 | 对大误差敏感，梯度稳定 |
| **MAE** | 1/n Σ\|ŷ-y\| | 回归 | 对异常值鲁棒，零点不可导 |
| **BCE** | -[y·log(ŷ) + (1-y)·log(1-ŷ)] | 二分类 | 配合 Sigmoid 输出 |
| **Cross Entropy** | -Σ y·log(ŷ) | 多分类 | 配合 Softmax 输出 |
| **Focal Loss** | -α(1-ŷ)ᵞ·log(ŷ) | 类别不均衡 | 降低易分样本权重 |

> 💬 **面试官**："为什么分类问题不用 MSE 用交叉熵？"
>
> 🎯 **你**："MSE 在分类问题上梯度信号弱。当预测概率接近 0 或 1 时，Sigmoid 的导数趋近于 0，MSE 的梯度也趋近于 0，模型学不动。交叉熵的梯度是 ŷ - y，和预测误差直接成正比，无论概率在哪都有足够梯度。"

---

#### 5. 优化器：怎么下山最快

```
梯度下降家族进化史：

SGD          : w = w - lr · ∇L        （最原始，震荡大）
  ↓
Momentum     : v = βv + ∇L            （积累动量，加速收敛）
               w = w - lr · v
  ↓
AdaGrad      : 累积梯度平方，自适应 lr  （学习率越调越小，容易停滞）
  ↓
RMSprop      : 指数移动平均梯度平方     （修复 AdaGrad 学习率衰减问题）
  ↓
Adam         : Momentum + RMSprop       （当前最常用，默认首选）
               一阶矩估计 + 二阶矩估计 + 偏差修正
```

**Adam 超参速记**：
- `lr` (α)：学习率，通常 1e-3 ~ 1e-5
- `β1`：一阶矩衰减，默认 0.9（动量）
- `β2`：二阶矩衰减，默认 0.999（RMSprop）
- `ε`：数值稳定，默认 1e-8

> 💬 **面试官**："Adam 和 SGD 怎么选？"
>
> 🎯 **你**："默认用 Adam，收敛快、对学习率不敏感。但 SGD + Momentum 在训练后期往往能找到更优的泛化解——所以很多大模型训练先 Adam 热身，再切 SGD 精调。"

#### 6. 正则化：防止过拟合的四大金刚

| 技术 | 原理 | 实现方式 | 效果 |
|---|---|---|---|
| **L2 正则化** | 权重衰减 | loss += λ·Σw² | 权重变小，模型更平滑 |
| **Dropout** | 随机失活 | 训练时以概率 p 丢弃神经元 | 防止共适应，强制冗余表达 |
| **BatchNorm** | 批标准化 | 每层输出标准化 + 可学习缩放 | 稳定训练、允许更大 lr、轻微正则 |
| **Early Stopping** | 早停 | 验证集 loss 不下降就停 | 防止训练过度 |

**BatchNorm 为什么有效？**（面试高频）
> ① **内部协变量偏移**：每层输入分布变化导致上层要不断适应，BN 固定分布；② **平滑损失曲面**：让优化 landscape 更平滑，允许更大学习率；③ **轻微正则化**：每个 batch 统计量不同，引入噪声。

> 💬 **面试官**："Dropout 训练和测试有什么区别？"
>
> 🎯 **你**："训练时随机丢弃，测试时不能丢（否则输出随机）。解决方案：训练时把保留的神经元输出除以 p（Inverted Dropout），测试时什么都不做直接前向——这样测试和训练的期望输出一致。"

#### 7. 梯度消失 vs 梯度爆炸

```
深度网络反向传播时：

梯度消失（Gradient Vanishing）
  └── 激活函数导数 < 1（如 Sigmoid 最大 0.25）
  └── 连乘后梯度指数级衰减
  └── 浅层参数几乎不更新
  └── 解决：ReLU、残差连接、更好的初始化

梯度爆炸（Gradient Exploding）
  └── 激活函数导数 > 1 或权重太大
  └── 连乘后梯度指数级增长
  └── 参数变成 NaN
  └── 解决：梯度裁剪（Gradient Clipping）、权重正则化
```

> 💬 **面试官**："ResNet 为什么能解决梯度消失？"
>
> 🎯 **你**："普通网络的梯度要穿过每一层连乘回去，深层时梯度趋于 0。ResNet 加了跳跃连接（Skip Connection），梯度可以直接从深层传到浅层——`∂L/∂x = ∂L/∂F + ∂L/∂x`，即使 ∂L/∂F 很小，∂L/∂x 至少还能传下去。"

#### 8. CNN / RNN / Transformer 速览

| 架构 | 核心机制 | 擅长 | 缺点 | 代表模型 |
|---|---|---|---|---|
| **CNN** | 卷积核局部连接 + 权值共享 | 空间特征（图像） | 长距离依赖弱 | ResNet, VGG |
| **RNN** | 时序隐藏状态传递 | 序列建模 | 并行差、长程遗忘 | LSTM, GRU |
| **Transformer** | 自注意力机制 | 并行、长距离依赖 | 计算量 O(n²) | BERT, GPT |

**Transformer 核心公式**（面试能默写是加分项）：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) · V

Multi-Head Attention = Concat(head₁, ..., headₕ) · W^O
where headᵢ = Attention(QWᵢ^Q, KWᵢ^K, VWᵢ^V)
```

> 💬 **面试官**："为什么 Transformer 除以 √dₖ？"
>
> 🎯 **你**："QK^T 的点积在维度高时数值很大，Softmax 会进入梯度极小的饱和区。除以 √dₖ 把方差缩回 1，让 Softmax 的梯度保持合理范围。"

### 🔥 高频面试连环问

**Q1：神经网络参数怎么初始化？全 0 行不行？**
> 不行。全 0 初始化导致所有神经元学到一样的东西（对称性破缺问题）。常用：① Xavier/Glorot 初始化（ tanh/Sigmoid，根据输入输出维度平衡方差）；② He 初始化（ReLU，方差设为 2/fan_in）；③ 正交初始化（RNN）。

**Q2：BatchNorm 放在激活函数前还是后？**
> 原始论文放激活函数前（Conv → BN → ReLU），但后续研究发现放后面也行。关键是保持一致。BN 前一般不加偏置，因为 BN 有自己的平移参数 β。

**Q3：学习率怎么调？**
> ①  warm-up：前几轮线性增大 lr，防止初始梯度大破坏预训练权重；② 学习率衰减：Step（每 N 轮降）、Cosine Annealing（余弦退火，平滑）、ReduceLROnPlateau（验证集 loss 不降就降）；③ 大 batch 配大 lr（Linear Scaling Rule）。

**Q4：Batch Size 怎么选？**
> 小 batch（32-64）：噪声大，泛化好，收敛不稳定；大 batch（1024+）：梯度估计准，训练快，但容易陷到 sharp minima（泛化差）。常用 256-512 折中。大 batch 训练要配合 LARS/LAMB 优化器。

**Q5：什么是过拟合的「Early Stopping」策略？**
> 监控验证集 loss，当连续 N 轮（patience）不降就停止训练，回退到最优 checkpoint。这是最便宜也最有效的正则化方法之一——不增加任何计算成本。

**Q6：模型训练不收敛，怎么排查？**
> ① 检查数据：标签对不对？有没有归一化？② 检查 loss：是不是一直不动或变成 NaN？③ 检查梯度：是不是梯度消失/爆炸？④ 检查学习率：太大震荡，太小不动；⑤ 检查代码：反向传播有没有漏？Loss 计算对不对？

用这个三层回答法：

```
第一层（直觉）：
"注意力就是『查字典』——Query 去查 Key-Value 字典，
  相似度高的 Key 对应的 Value 权重就大。"

```
