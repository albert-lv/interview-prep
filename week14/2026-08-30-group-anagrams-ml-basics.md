## 一、今日算法题：字母异位词分组

### 题目

给定一个字符串数组 `strs`，将**字母异位词**组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的字母得到的一个新单词，所有源单词中的字母通常恰好只用一次。

**示例：**
```
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

输入: strs = [""]
输出: [[""]]

输入: strs = ["a"]
输出: [["a"]]
```

**约束：**
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

---

### 思路

**核心洞察**：字母异位词排序后得到的字符串相同。

例如：`"eat"`、`"tea"`、`"ate"` 排序后都是 `"aet"`。所以可以用**排序后的字符串作为哈希表的 key**，将所有异位词分组。

**为什么想到排序？**
- 异位词的本质是字符组成相同、排列不同
- 排序相当于把不同排列归一到同一个"标准形式"
- 这和特征工程里的**标准化/归一化**思想一脉相承：把不同形式的数据映射到统一的表示空间

**面试时怎么展开？**
> "这道题的本质是找到一个稳定的特征表示。排序后的字符串就是这种表示——不管原始排列怎么变，特征不变。这和机器学习里做特征编码是一个道理。"

---

### 代码实现

#### Python 解法（排序作为 key）

```python
from collections import defaultdict
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)
        
        for s in strs:
            # 排序后的字符串作为 key
            key = ''.join(sorted(s))
            groups[key].append(s)
        
        return list(groups.values())
```

#### Python 解法（字符计数编码优化）

```python
from collections import defaultdict
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        """
        优化：用字符计数数组代替排序
        把 26 个字母的计数变成 tuple 作为 key
        时间从 O(N * K log K) 降到 O(N * K)
        """
        groups = defaultdict(list)
        
        for s in strs:
            count = [0] * 26
            for ch in s:
                count[ord(ch) - ord('a')] += 1
            # tuple 才能做 dict key
            groups[tuple(count)].append(s)
        
        return list(groups.values())
```

#### Go 解法（字符计数编码）

```go
package main

import (
	"fmt"
	"strconv"
	"strings"
)

func groupAnagrams(strs []string) [][]string {
	groups := make(map[string][]string)
	
	for _, s := range strs {
		// 26 个字母的计数
		count := make([]int, 26)
		for i := 0; i < len(s); i++ {
			count[s[i]-'a']++
		}
		
		// 编码成字符串 key，例如 "1#2#0#..."
		var keyParts []string
		for _, c := range count {
			keyParts = append(keyParts, strconv.Itoa(c))
		}
		key := strings.Join(keyParts, "#")
		
		groups[key] = append(groups[key], s)
	}
	
	result := make([][]string, 0, len(groups))
	for _, group := range groups {
		result = append(result, group)
	}
	return result
}

func main() {
	strs := []string{"eat", "tea", "tan", "ate", "nat", "bat"}
	fmt.Println(groupAnagrams(strs))
	// 输出顺序不固定，内容正确即可
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|---|---|---|---|
| 排序 key | O(N · K log K) | O(N · K) | N=字符串数，K=最大字符串长度 |
| 字符计数 | **O(N · K)** ✅ | O(N · K) | 最优解法，省去排序开销 |

> 💡 **面试提醒**：先给排序解法（直观好懂），主动提出优化到计数解法（展示你考虑性能）。这是加分项。

### 面试官 Follow-up

**Q：如果字符串包含 Unicode 字符怎么办？**
> 计数数组不能用固定 26 长度了。可以用 `map[rune]int` 做计数，然后排序 map 的 key-value 对生成字符串 key。或者直接用排序解法，不受字符集限制。

**Q：空间复杂度还能优化吗？**
> 输出本身就需要 O(N·K)，这是下限。但如果不算输出，可以只用 O(K) 额外空间（计数数组）。

**Q：和机器学习有什么关系？**
> 这就是**特征提取**——把变长的原始数据（字符串）映射到固定维度的特征空间（26维计数向量）。词袋模型（Bag of Words）就是这个思路：不在乎词序，只在乎词频。

## 二、面试技巧：机器学习基础与特征工程

### 🎯 核心速查卡

#### 1. 机器学习三大范式

| 范式 | 数据 | 目标 | 经典算法 | 面试高频 |
|---|---|---|---|---|
| **监督学习** | 有标签 | 学映射 X→Y | 线性回归、决策树、SVM、神经网络 | 🔥🔥🔥 |
| **无监督学习** | 无标签 | 发现隐藏结构 | K-Means、PCA、DBSCAN、AutoEncoder | 🔥🔥 |
| **强化学习** | 环境交互 | 学最优策略 | Q-Learning、PPO、DQN | 🔥🔥🔥（大模型时代） |

> 💬 **面试官**："监督和无监督的区别？"
>
> 🎯 **你**："监督学习像有老师批改作业——数据有标准答案，模型学的是输入到输出的映射。无监督像自学——没有标准答案，模型自己发现数据里的规律，比如聚类或降维。"

#### 2. 特征工程：把原始数据变成模型能吃的样子

```
原始数据 → 清洗 → 转换 → 选择 → 模型输入
            ↓      ↓      ↓
          缺失值  标准化  相关性
          异常值  编码    重要性
          重复值  降维    方差筛选
```

**标准化 vs 归一化**（面试必问）

| 方法 | 公式 | 适用场景 | 特点 |
|---|---|---|---|
| **标准化 (Z-Score)** | (x - μ) / σ | 数据近似正态分布、需要比较不同量纲 | 均值为0，方差为1，**不怕异常值** |
| **归一化 (Min-Max)** | (x - min) / (max - min) | 需要固定范围 [0,1]、神经网络输入 | 受异常值影响大 |
| ** Robust Scaling** | (x - median) / IQR | 有极端异常值 | 用中位数和四分位距，更稳健 |

> 💬 **面试官**："为什么神经网络输入要标准化？"
>
> 🎯 **你**："三个原因：① 梯度下降收敛更快（不同特征尺度一致，等高线更圆）；② 避免某些特征因数值大主导损失；③ 激活函数在0附近有最好梯度（比如 tanh、sigmoid）。"

**类别特征编码**

| 编码方式 | 适用 | 缺点 |
|---|---|---|
| **One-Hot** | 类别数少（<10） | 高基数时维度爆炸 |
| **Label Encoding** | 有序类别（低<中<高） | 无序类别会引入虚假序关系 |
| **Target Encoding** | 高基数类别 | 容易过拟合，要加平滑 |
| **Embedding** | 深度学习、高基数 | 需要训练，效果最好 |

> 💬 **面试官**："用户ID怎么做特征？"
>
> 🎯 **你**："用户ID 是高基数类别（可能百万级），One-Hot 不行。方案：① Embedding 层学习低维稠密向量（深度学习）；② Target Encoding 用统计值代替（如该用户平均点击率）；③ 聚类降维后分组。"

#### 3. 模型评估指标

**分类问题**

| 指标 | 公式/定义 | 什么时候用 |
|---|---|---|
| **Accuracy** | (TP+TN) / 总数 | 类别均衡时 |
| **Precision** | TP / (TP+FP) | **减少误报**（垃圾邮件过滤：宁可放过，别错杀） |
| **Recall** | TP / (TP+FN) | **减少漏报**（癌症筛查：宁可错杀，别放过） |
| **F1-Score** | 2·P·R / (P+R) | 需要平衡 P 和 R |
| **AUC-ROC** | ROC 曲线下面积 | 评估排序能力，**不受阈值影响** |
| **AUC-PR** | PR 曲线下面积 | 类别极度不均衡时比 ROC 更可靠 |

> 💬 **面试官**："AUC 0.8 是什么意思？"
>
> 🎯 **你**："随机抽一个正样本和一个负样本，模型给正样本打分更高的概率是 80%。AUC 不看阈值，只看排序能力——这是它最大的优点。"

**回归问题**

| 指标 | 公式 | 特点 |
|---|---|---|
| **MSE** | 平均平方误差 | 对大误差惩罚重（平方放大） |
| **RMSE** | MSE 开根号 | 单位和原数据一致，好解释 |
| **MAE** | 平均绝对误差 | 对异常值更稳健 |
| **R²** | 1 - SSE/SST | 解释模型拟合程度，1 为完美 |

#### 4. 过拟合 vs 欠拟合

```
                    模型复杂度
  高误差 ↑        低 ──────→ 高
         │  欠拟合 │  正好  │  过拟合
  训练集 │   高    │  低   │  极低
  验证集 │   高    │  低   │  高
         └────────────────────────→
```

**解决过拟合（模型太复杂，记住噪声）**
- **数据层面**：增大数据量、数据增强（图像翻转/裁剪/加噪）
- **模型层面**：简化模型、减少参数、Dropout、Early Stopping
- **正则化**：L1（产生稀疏性，自动特征选择）、L2（权重衰减，更平滑）

**解决欠拟合（模型太简单，学不到规律）**
- 增加模型复杂度（更多层/更多特征）
- 减少正则化强度
- 特征工程：构造更有表达力的特征
- 换更强的模型

> 💬 **面试官**："L1 和 L2 正则化的区别？"
>
> 🎯 **你**："直观理解：L2 让权重都变小但不为零（像一个橡皮筋把权重往0拉），模型更平滑；L1 让部分权重直接变零（像剪刀剪掉不重要的特征），自动做特征选择。从优化角度，L2 有解析解，L1 没有。"

#### 5. 偏差-方差分解

```
总误差 = 偏差² + 方差 + 噪声

• 偏差大 → 欠拟合 → 模型太简单，对真实规律假设太强
• 方差大 → 过拟合 → 模型太复杂，对训练数据太敏感

 Bagging（如随机森林）→ 降低方差
 Boosting（如 XGBoost）→ 降低偏差
```

> 💬 **面试官**："怎么判断是偏差问题还是方差问题？"
>
> 🎯 **你**："看学习曲线：训练误差和验证误差都高→偏差问题（欠拟合）；训练误差低但验证误差高→方差问题（过拟合）。也可以用交叉验证：不同折上表现差异大→方差大。"

### 🔥 高频面试连环问

**Q1：分类问题选什么损失函数？**
> 二分类用二元交叉熵（BCE），多分类用交叉熵（CE）/ Softmax + NLL。回归用 MSE/MAE。如果类别不均衡，加权重或换 Focal Loss。

**Q2：怎么处理类别不均衡？**
> ① 采样：过采样（SMOTE）/ 欠采样；② 类别权重：损失函数里给少数类更高权重；③ 换评估指标：别用 Accuracy，用 F1 或 AUC-PR；④ 集成：EasyEnsemble、BalanceCascade。

**Q3：特征重要性怎么算？**
> ① 树模型：Gini 不纯度下降或信息增益；② 线性模型：权重绝对值；③ Permutation Importance：打乱某个特征看性能下降多少；④ SHAP：博弈论方法，最精细但计算贵。

**Q4：交叉验证怎么做？K-Fold 和留一法区别？**
> K-Fold：分成 K 份，轮流拿一份做验证，其余训练，K 次结果平均。留一法（LOO）：K=N，每轮只留一个样本验证。K-Fold 是平衡之选（通常 K=5/10），LOO 计算量太大但偏差小。

**Q5：什么是信息增益？ID3 和 C4.5 的区别？**
> 信息增益 = 划分前的熵 - 划分后的加权平均熵，衡量特征划分后不确定性减少了多少。ID3 用信息增益选特征，偏向多值特征；C4.5 用信息增益率（增益/分裂信息）修正这个偏置，还能处理连续值和缺失值。

#### 一句话速记

| 概念 | 一句话 |
|---|---|
| 梯度下降 | 沿着损失函数下降最快的方向走，步子大小叫学习率 |
| 反向传播 | 链式法则从输出层往输入层传梯度，算每个参数该调多少 |
| Dropout | 训练时随机"关掉"一些神经元，防止它们互相依赖 |
| BatchNorm | 每层输出做标准化，让训练更稳更快 |
| 学习率衰减 | 训练后期把步子迈小点，避免在最优解附近震荡 |
