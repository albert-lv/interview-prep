## 今日算法题

### 题目：最大子数组和

**描述**：给定一个整数数组 `nums`，找到一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**示例**：
- `nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]` → 输出 `6`
  - 连续子数组 `[4, -1, 2, 1]` 的和最大，为 `6`
- `nums = [1]` → 输出 `1`
- `nums = [-1]` → 输出 `-1`（必须选至少一个元素）

---

### 解题思路

**核心洞察**：这是Kadane算法的经典应用。`dp[i]` 表示「以第 `i` 个元素结尾」的连续子数组的最大和。

**关键问题**：以 `nums[i]` 结尾的最大和子数组，要么只包含 `nums[i]` 自己，要么是把 `nums[i]` 接在「以 `nums[i-1]` 结尾的最大和子数组」后面。

**状态转移方程**：
```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```
- 如果 `dp[i-1]` 是负数，那前面的和就是累赘，不如从 `nums[i]` 重新开始
- 如果 `dp[i-1]` 是正数，那就接上，让和更大

**全局答案**：`max(dp[i]) for all i` —— 以每个位置结尾的最大和里，取最大的那个

**记忆口诀**：前面是累赘就甩掉，前面是正资产就继承。

---

### 代码实现

#### 基础DP版本（面试推荐）

```python
def maxSubArray(nums: list[int]) -> int:
    n = len(nums)
    # dp[i]: 以 nums[i] 结尾的连续子数组的最大和
    dp = [0] * n
    dp[0] = nums[0]
    
    for i in range(1, n):
        # 要么自己单干，要么继承前面的家业
        dp[i] = max(nums[i], dp[i-1] + nums[i])
    
    return max(dp)
```

#### 空间优化版本（O(1) 空间）

```python
def maxSubArray(nums: list[int]) -> int:
    # 只需要维护：当前以 i 结尾的最大和，以及全局最大值
    current_sum = nums[0]
    max_sum = nums[0]
    
    for i in range(1, len(nums)):
        # 前面的和如果是负的，不如从零开始
        current_sum = max(nums[i], current_sum + nums[i])
        # 更新全局最大
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```

> 这个版本就是正宗的 **Kadane算法**，空间复杂度 O(1)，面试写到这个版本加分。

---

### 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| **时间** | O(n) | 只需要遍历一次数组 |
| **空间** | O(n) → O(1) | 基础版用dp数组，优化版只需两个变量 |

---

### 经典变体

| 变体 | 核心变化 | 解法思路 |
|------|---------|---------|
| **乘积最大子数组** | 和 → 乘积 | 需要同时维护最大和最小（负数乘负数变正），`dp_max[i]` 和 `dp_min[i]` 同时转移 |
| **环形子数组的最大和** | 数组是环形的 | 两种情况：1) 最大和在数组中间（普通Kadane）；2) 最大和跨越首尾 = 总和 - 最小子数组和（注意全负的情况） |
| **最大子数组和（至少k个元素）** | 子数组长度 ≥ k | 前缀和 + 单调队列，维护最小前缀和 |
| **最大子矩阵和** | 一维 → 二维 | 枚举上下边界，把列压缩成一维，再跑Kadane |

## 面试技巧

### 1. 如何向面试官解释 Kadane 思路

**开场白**：
> "这道题的核心观察是：一个最大和的连续子数组，它的任意前缀也应该是以该位置结尾的最大和子数组。否则我们还不如换个起点。"

**用例子现场推演**（拿 `[-2, 1, -3, 4, -1, 2, 1]`）：

```
位置:  -2   1   -3   4   -1   2   1
以i结尾: -2   1   -2   4    3   5   6  ← 当前最优
全局最大: -2   1    1   4    4   5   6  ← 答案
```

**三句话讲清状态转移**：
1. 以 `i` 结尾的最大和 = 要么自己重新开始，要么继承 `i-1` 的结果
2. 如果前面的和是负数，继承只会拖后腿，不如自己单干
3. 全局答案 = 所有「以i结尾的最大和」里面取最大

### 2. 常见追问及应对

| 追问 | 应对策略 |
|------|----------|
| "空间能优化吗？" | 答：可以。只关心前一个位置的值，两个变量就够了，O(1)空间 |
| "能输出具体的子数组吗？" | 答：记录 `current_sum` 切换时的起点索引，全局更新时记录终点索引 |
| "数组里有0怎么办？" | 答：不影响。0不会改变正负性，逻辑完全一致 |
| "如果是乘积最大呢？" | 答：需要同时维护最大和最小，因为负数×负数可能变最大。`dp_max[i] = max(nums[i], dp_max[i-1]*nums[i], dp_min[i-1]*nums[i])`，`dp_min` 同理 |
| "环形数组呢？" | 答：两种情况：普通最大子数组和 vs 总和 - 最小子数组和。注意如果全是负数，第二种情况会错，需要额外判断 |
| "Kadane算法的时间复杂度能更好吗？" | 答：O(n) 已经最优了，每个元素至少要看一次。但如果数组是部分有序的，分治法可以做到 O(n log n)，不过面试一般不考 |

### 3. 面试现场 checklist

- [ ] 先确认数组是否可能为空（LeetCode题目保证至少一个元素，但面试要问）
- [ ] 确认「至少选一个元素」还是「可以选空子数组（和为0）」
- [ ] 先写基础DP版本，再主动优化到O(1)空间
- [ ] 用手写例子走一遍代码，确认状态转移正确
- [ ] 提到变体（乘积最大、环形数组），展示知识面

### 4. 易错点提醒

⚠️ **初始化陷阱**：`current_sum` 和 `max_sum` 都应该初始化为 `nums[0]`，不是0。如果全数组都是负数，初始化为0就会错。  
⚠️ **空数组处理**：如果题目允许空子数组，答案应该是0。但本题要求至少一个元素。  
⚠️ **整数溢出**：如果数组全是 `INT_MAX`，累加可能溢出。Python无所谓，C++/Java要注意。  
⚠️ **乘积变体**：不要只维护最大值，负数乘负数会变成最大，必须同时维护最小值。
