## 今日算法题

### 题目：编辑距离

**描述**：给你两个字符串 `word1` 和 `word2`，计算出将 `word1` 转换成 `word2` 所使用的最少操作数。你可以对一个字符串进行如下三种操作：
- 插入一个字符
- 删除一个字符
- 替换一个字符

**示例**：
- `word1 = "horse"`, `word2 = "ros"` → 输出 `3`
  - horse → rorse (替换 'h' 为 'r')
  - rorse → rose (删除 'r')
  - rose → ros (删除 'e')
- `word1 = "intention"`, `word2 = "execution"` → 输出 `5`

---

### 解题思路

**核心洞察**：这是一道经典的二维DP。`dp[i][j]` 表示 `word1[0..i-1]` 转换成 `word2[0..j-1]` 的最小编辑距离。

**状态转移方程**：
- 如果 `word1[i-1] == word2[j-1]`：不需要操作，`dp[i][j] = dp[i-1][j-1]`
- 如果不相等：取三种操作的最小值 + 1
  - 删除：`dp[i-1][j] + 1`（删除 word1[i-1]）
  - 插入：`dp[i][j-1] + 1`（在 word1 末尾插入 word2[j-1]）
  - 替换：`dp[i-1][j-1] + 1`（把 word1[i-1] 替换成 word2[j-1]）

**初始状态**：
- `dp[i][0] = i`：word1 删除 i 个字符变成空串
- `dp[0][j] = j`：空串插入 j 个字符变成 word2

**记忆口诀**：相等对角抄，不相等三选一取最小。

---

### 代码实现

```python
def minDistance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    # dp[i][j]: word1前i个字符 -> word2前j个字符的最小编辑距离
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 初始化边界
    for i in range(m + 1):
        dp[i][0] = i  # 删除i次
    for j in range(n + 1):
        dp[0][j] = j  # 插入j次
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]  # 字符相等，无需操作
            else:
                dp[i][j] = min(
                    dp[i-1][j],     # 删除
                    dp[i][j-1],     # 插入
                    dp[i-1][j-1]    # 替换
                ) + 1
    
    return dp[m][n]
```

---

### 空间优化版本（一维数组）

```python
def minDistance_optimized(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    # 确保 word1 是较短的，减少空间
    if m < n:
        return minDistance_optimized(word2, word1)
    
    dp = list(range(n + 1))  # 上一行
    
    for i in range(1, m + 1):
        prev = dp[0]  # dp[i-1][j-1]
        dp[0] = i     # 当前行第一个元素
        for j in range(1, n + 1):
            temp = dp[j]  # 保存 dp[i-1][j] 供下一轮使用
            if word1[i-1] == word2[j-1]:
                dp[j] = prev
            else:
                dp[j] = min(dp[j], dp[j-1], prev) + 1
            prev = temp
    
    return dp[n]
```

---

### 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| **时间** | O(m × n) | 双重循环遍历两个字符串 |
| **空间** | O(m × n) | 二维DP数组（优化后为 O(min(m,n))） |

## 面试技巧

### 1. 如何向面试官解释思路

**开场白**：
> "这道题我想到用动态规划。定义 `dp[i][j]` 为第一个字符串前i个字符转成第二个字符串前j个字符的最小编辑距离。"

**画图辅助**：
- 随手画一个 5×5 的小表格，填几个值
- 让面试官直观看到「相等就对角线继承，不相等就三选一」
- 这是展示你思维清晰度的最佳时机

**三句话讲清状态转移**：
1. 字符相同 → 免费，直接继承 `dp[i-1][j-1]`
2. 字符不同 → 删、插、换，三选一 + 1
3. 边界：一个空串转成另一个，长度差就是操作数

### 2. 常见追问及应对

| 追问 | 应对策略 |
|------|----------|
| "空间能优化吗？" | 答：可以滚动数组。只依赖上一行，用一维数组 + 临时变量保存对角线值 |
| "时间能优化吗？" | 答：如果字符串很长但差异很小，可以用最短编辑距离算法（如 Ukkonen 算法）降到 O(min(m,n) + 编辑距离) |
| "实际应用场景？" | 拼写纠错、DNA 序列比对、git diff、模糊搜索（如 `fzf`） |
| "怎么输出具体操作序列？" | 回溯 DP 表，从 `dp[m][n]` 逆推每一步选了哪个操作 |

### 3. 面试现场 checklist

- [ ] 先确认空串边界情况（`""` → `"abc"` 这种）
- [ ] 状态定义讲清楚下标含义（前i个字符 vs 第i个字符）
- [ ] 写完二维版本后，主动提「可以空间优化到一维」
- [ ] 手速测试：5分钟内在纸上写出完整代码

### 4. 易错点提醒

⚠️ **下标混乱**：`dp[i][j]` 对应 `word1[i-1]` 和 `word2[j-1]`，不是 `word1[i]`  
⚠️ **空间优化时**：需要用临时变量 `prev` 保存左上角的值，因为一维数组会被覆盖  
⚠️ **初始化顺序**：先处理 `dp[i][0]` 和 `dp[0][j]`，再填内部
