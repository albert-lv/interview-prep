## 今日算法题

### 题目：整数拆分

**描述**：给定一个正整数 `n`，将其拆分为至少两个正整数的和，并使这些整数的乘积最大化。返回最大乘积。

**说明**：
- `n ≥ 2`（至少要拆成两个数）
- 拆分的数必须是正整数

**示例**：
- `n = 2` → 拆分为 `1 + 1`，乘积 `1 × 1 = 1`，返回 `1`
- `n = 10` → 最优拆分为 `3 + 3 + 4`，乘积 `3 × 3 × 4 = 36`，返回 `36`
- `n = 8` → 最优拆分为 `3 + 3 + 2`，乘积 `3 × 3 × 2 = 18`，返回 `18`

---

### 解题思路

**核心洞察**：这道题和「单词拆分」一脉相承，但状态从"能不能"变成了"最大是多少"——从布尔型 DP 进化到数值型 DP。

**状态定义**：
- `dp[i]`：将正整数 `i` 拆分成至少两个正整数之和后，这些整数的最大乘积
- `dp[1] = 0`（1 不能拆分，乘积为 0）

**状态转移方程**：
```
dp[i] = max(
    j × (i - j),           // 只拆成两个数：j 和 i-j
    j × dp[i - j],         // 拆成 j 和 (i-j) 的最优拆分
    对于所有 j ∈ [1, i-1]
)
```

**解释**：对于整数 `i`，枚举第一个拆分出来的数 `j`（从 1 到 i-1）：
1. 方案一：只拆一次，乘积 = `j × (i-j)`
2. 方案二：继续拆 `(i-j)`，乘积 = `j × dp[i-j]`
3. 取所有方案的最大值

**为什么不需要 `dp[j]`？**
因为 `j` 从 1 开始枚举，当我们枚举到某个 `j` 时，所有比 `j` 小的情况都已经考虑过了。但这里有个技巧：`j` 只需要枚举到 `i/2`，因为 `j` 和 `i-j` 是对称的。

**数学规律（面试加分项）**：
> 数学证明：当拆分出的数尽可能接近 `e ≈ 2.718` 时，乘积最大。因此最优策略是尽可能多地拆出 3。
> 
> 快速解法：
> - 如果 `n % 3 == 0`：全部拆成 3，答案 = `3^(n/3)`
> - 如果 `n % 3 == 1`：拆出一个 4（两个 2），其余拆 3，答案 = `3^((n-4)/3) × 4`
> - 如果 `n % 3 == 2`：拆出一个 2，其余拆 3，答案 = `3^((n-2)/3) × 2`

### 代码实现

#### 基础DP版本（面试推荐）

```python
def integerBreak(n: int) -> int:
    # dp[i] 表示将 i 拆分后的最大乘积
    dp = [0] * (n + 1)
    dp[1] = 0  # 1 无法拆分
    
    for i in range(2, n + 1):
        for j in range(1, i // 2 + 1):  # 只需要枚举到 i/2
            # 方案1: 只拆一次
            # 方案2: 继续拆 (i-j)
            dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
    
    return dp[n]
```

#### 贪心/数学版本（代码面试中展示数学素养）

```python
def integerBreakMath(n: int) -> int:
    if n <= 3:
        return n - 1  # 2→1, 3→2（必须拆成至少两个数）
    
    quotient, remainder = divmod(n, 3)
    
    if remainder == 0:
        return 3 ** quotient
    elif remainder == 1:
        return 3 ** (quotient - 1) * 4  # 把一个3和1变成4
    else:  # remainder == 2
        return 3 ** quotient * 2
```

> 💡 贪心版本时间复杂度 O(1)，空间复杂度 O(1)。面试时先写 DP 展示思维过程，再提贪心解法展示数学功底。

### 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| **时间（DP）** | O(n²) | 外层 i 从 2 到 n，内层 j 从 1 到 i/2 |
| **空间（DP）** | O(n) | dp 数组长度 n+1 |
| **时间（贪心）** | O(1) | 只有几次数学运算 |
| **空间（贪心）** | O(1) | 常数空间 |

### 经典变体

| 变体 | 核心变化 | 解法思路 |
|------|---------|---------|
| **整数拆分（至少拆 k 个数）** | 要求至少拆成 k 个 | 增加一维状态 `dp[i][k]`，或者用滚动数组优化 |
| **整数拆分（带最少拆分个数）** | 求最大乘积且拆分个数最少 | 在 dp 状态中增加计数维度 |
| **绳子切割** | 一根长度为 n 的绳子，剪成整数段，求最大乘积 | 和本题完全相同，只是换了个故事 |
| **完全平方数拆分** | 拆成完全平方数之和，求最少个数 | `dp[i] = min(dp[i - j²] + 1)`，类似完全背包 |

## 面试技巧

### 1. 如何向面试官解释思路

**开场白**：
> "这道题是整数拆分的经典 DP。我们定义 `dp[i]` 为将 `i` 拆分后的最大乘积。对于每个 `i`，枚举第一个拆出来的数 `j`，然后比较两种方案：只拆一次 `j × (i-j)`，或者继续拆 `(i-j)` 得到 `j × dp[i-j]`。"

**画个图现场推演**（拿 `n = 10`）：

```
i=2: j=1 → max(1×1) = 1                  → dp[2]=1
i=3: j=1 → max(1×2, 1×dp[2]=1) = 2       → dp[3]=2
i=4: j=1 → max(1×3, 1×dp[3]=2) = 3
      j=2 → max(2×2, 2×dp[2]=2) = 4       → dp[4]=4
i=5: j=1 → max(1×4, 1×dp[4]=4) = 4
      j=2 → max(2×3, 2×dp[3]=4) = 6       → dp[5]=6
...
i=10: 枚举 j=1..5，最终 dp[10]=36 (3+3+4)
```

**三句话讲清**：
1. `dp[i]` = 把 `i` 拆分后的最大乘积
2. 枚举第一个数 `j`，比较"只拆一次"和"继续拆后面部分"
3. 答案是 `dp[n]`

### 2. 常见追问及应对

| 追问 | 应对策略 |
|------|---------|
| "时间复杂度能优化吗？" | 答：可以。数学证明拆成尽可能多的 3 最优。贪心 O(1) 解法：n%3 分三种情况 |
| "为什么拆成 3 最优？" | 答：求导证明 f(x) = x^(n/x) 在 x=e≈2.718 取最大值，整数中最接近的是 3 |
| "如果要求至少拆成 k 段呢？" | 答：增加维度 `dp[i][m]` 表示把 i 拆成 m 段的最大乘积，或者换思路用多项式 DP |
| "如果数字范围很大（n=10⁹）呢？" | 答：必须用贪心 O(1) 解法，DP 的 O(n²) 会超时 |
| "DP 版本里为什么 j 只枚举到 i/2？" | 答：因为 j 和 i-j 对称，枚举 j > i/2 会和之前的情况重复 |

### 4. 易错点提醒

⚠️ **dp[1] = 0**：1 不能拆分，如果设为 1 会影响后续计算
⚠️ **至少拆两个数**：`n=2` 只能拆成 `1+1`，乘积是 1，不是 2
⚠️ **j 的枚举范围**：只需要到 `i//2`，因为对称
⚠️ **比较时漏掉 `j * (i-j)`**：不能只比较 `j * dp[i-j]`，还要考虑只拆一次的情况
⚠️ **贪心版本 n≤3 的特判**：2→1, 3→2，因为必须至少拆两个数
