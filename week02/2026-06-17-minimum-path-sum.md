## 今日算法题

### 题目：最小路径和

**描述**：给定一个包含非负整数的 `m × n` 网格 `grid`，找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**移动规则**：每次只能向下或向右移动一步。

**示例**：
```
输入: grid = [
  [1, 3, 1],
  [1, 5, 1],
  [4, 2, 1]
]
输出: 7
解释: 路径 1→3→1→1→1 的总和最小，为 7
```

---

### 解题思路

**核心洞察**：这是从「一维线性 DP」到「二维网格 DP」的进化。和第 6 天的「不同路径」是同胞兄弟——那道题求路径数，这道题求路径和。

**状态定义**：
- `dp[i][j]`：从左上角 `(0, 0)` 走到 `(i, j)` 的最小路径和

**状态转移方程**：
```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
```
- 从上方 `(i-1, j)` 来，或者从左边 `(i, j-1)` 来
- 取两者中较小的路径和，加上当前格子的值

**初始条件**：
- `dp[0][0] = grid[0][0]`（起点）
- 第一行：`dp[0][j] = dp[0][j-1] + grid[0][j]`（只能从左边来）
- 第一列：`dp[i][0] = dp[i-1][0] + grid[i][0]`（只能从上边来）

---

### 代码实现

#### 基础二维DP版本（面试推荐，先写这个）

```python
def minPathSum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    
    # dp[i][j] = 从 (0,0) 到 (i,j) 的最小路径和
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    
    # 初始化第一行（只能从左往右走）
    for j in range(1, n):
        dp[0][j] = dp[0][j-1] + grid[0][j]
    
    # 初始化第一列（只能从上往下走）
    for i in range(1, m):
        dp[i][0] = dp[i-1][0] + grid[i][0]
    
    # 填充剩余格子
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
    
    return dp[m-1][n-1]
```

#### 空间优化：一维滚动数组（面试进阶）

> 💡 核心观察：计算 `dp[i][j]` 时，只需要「上一行同一列」和「当前行前一列」。所以可以把二维压成一维。

```python
def minPathSum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    dp = [0] * n
    dp[0] = grid[0][0]
    
    # 初始化第一行（复用一维数组）
    for j in range(1, n):
        dp[j] = dp[j-1] + grid[0][j]
    
    for i in range(1, m):
        dp[0] += grid[i][0]  # 第一列只能从上边来
        for j in range(1, n):
            # dp[j] 还没更新 = 上一行的 dp[i-1][j]
            # dp[j-1] 已经更新 = 当前行的 dp[i][j-1]
            dp[j] = grid[i][j] + min(dp[j], dp[j-1])
    
    return dp[n-1]
```

> **面试话术**：「先用二维 DP 展示思路，再优化到一维。注意 `dp[j]` 在被覆盖之前存的是上一行的值，这就是滚动数组的精髓。」

#### 终极优化：原地修改（如果允许修改输入）

```python
def minPathSum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    
    # 第一行
    for j in range(1, n):
        grid[0][j] += grid[0][j-1]
    
    # 第一列
    for i in range(1, m):
        grid[i][0] += grid[i-1][0]
    
    # 其余
    for i in range(1, m):
        for j in range(1, n):
            grid[i][j] += min(grid[i-1][j], grid[i][j-1])
    
    return grid[m-1][n-1]
```

> ⚠️ 面试时先问面试官「能不能修改输入」，再决定是否用原地优化。不要自作主张改输入。

### 复杂度分析

| 维度 | 基础DP | 滚动数组 | 原地修改 |
|------|--------|----------|----------|
| **时间** | O(mn) | O(mn) | O(mn) |
| **空间** | O(mn) | O(n) | O(1) |

> 时间都是 O(mn)，因为每个格子至少访问一次。空间优化是面试加分项。

### 经典变体

| 变体 | 核心变化 | 解法思路 |
|------|---------|---------|
| **不同路径**（Day 6） | 求路径数，不是路径和 | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` |
| **最小路径和** | 求最小路径和 | `dp[i][j] = grid[i][j] + min(...)` |
| **最大路径和** | 求最大路径和 | `dp[i][j] = grid[i][j] + max(...)` |
| **三角形最小路径和** | 三角形结构，移动规则不同 | 自底向上 DP，`dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])` |
| **障碍物网格** | 网格中有障碍物（值为1） | 障碍物处 `dp = inf`，其余正常转移 |

## 面试技巧

### 1. 如何向面试官解释思路

**开场白**：
> "这道题是经典的二维网格 DP。我们定义 `dp[i][j]` 为从左上角走到 `(i, j)` 的最小路径和。因为每次只能向下或向右，所以走到 `(i, j)` 的路径必然是从上方 `(i-1, j)` 或左边 `(i, j-1)` 过来的。我们取两者中较小的路径和，加上当前格子的值。"

**现场画个图**（拿 3×3 例子）：

```
grid:          dp（最小路径和）:
1  3  1        1   4   5
1  5  1        2   7   6
4  2  1        6   8   7

第一行：1 → 1+3=4 → 4+1=5
第一列：1 → 1+1=2 → 2+4=6
(1,1): 5 + min(2, 4) = 7
(1,2): 1 + min(7, 5) = 6
(2,1): 2 + min(6, 7) = 8
(2,2): 1 + min(8, 6) = 7  ← 答案
```

**三句话讲清**：
1. `dp[i][j]` = 从起点到 `(i,j)` 的最小路径和
2. 只能从上方或左方来，取 `min(上方, 左方)` + 当前格
3. 先填第一行和第一列（只有一条路），再填其余

### 2. 常见追问及应对

| 追问 | 应对策略 |
|------|---------|
| "空间复杂度能优化吗？" | 答：可以。用一维滚动数组，只需要 O(n) 空间。`dp[j]` 更新前存的是上一行的值，更新后存的是当前行的值。 |
| "如果允许修改输入呢？" | 答：原地修改，O(1) 额外空间。但面试时要先问能不能改输入。 |
| "如果网格里有负数呢？" | 答：题目给的是非负数，但如果有负数，DP 仍然适用，只是不能贪心（比如全选负数反而最小）。 |
| "如果只能向下、向右、向右下走呢？" | 答：增加一个来源 `dp[i-1][j-1]`，转移方程变成 `grid[i][j] + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`。 |
| "和『不同路径』这道题的区别？" | 答：「不同路径」求路径数量，用加法；「最小路径和」求路径权重，用 `min` + 加法。结构几乎一样。 |
| "第一行/第一列的初始化能合并吗？" | 答：可以。先初始化 `dp[0][0]`，然后双重循环遍历，内部用 `if i>0` 和 `if j>0` 判断边界。但分开写更清晰。 |

### 3. 面试现场 checklist

- [ ] 确认移动规则：只能向下或向右？（有的题可以斜着走）
- [ ] 确认网格大小：`m × n` 至少 1×1，不用处理空网格
- [ ] 先写二维 DP 版本，保证思路清晰
- [ ] 主动提出空间优化（滚动数组 / 原地修改）
- [ ] 解释滚动数组时强调：`dp[j]` 的旧值是上一行，新值是当前行
- [ ] 对比「不同路径」和「最小路径和」的异同（展示融会贯通）

### 4. 易错点提醒

⚠️ **第一行和第一列的初始化**：不能直接用通用公式，因为 `i-1` 或 `j-1` 会越界
⚠️ **滚动数组中 `dp[0]` 的更新**：每一行开始前要单独更新 `dp[0] += grid[i][0]`（第一列只能从上边来）
⚠️ **原地修改先问面试官**：别自作主张改输入，有些面试官在意这个
⚠️ **混淆「最小路径和」和「最大路径和」**：看清楚题目要求，`min` 和 `max` 一字之差
⚠️ **返回值坐标**：`dp[m-1][n-1]`，不是 `dp[m][n]`
