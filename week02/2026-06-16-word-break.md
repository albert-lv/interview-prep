## 今日算法题

### 题目：单词拆分

**描述**：给定一个非空字符串 `s` 和一个包含非空单词列表的字典 `wordDict`，判定 `s` 是否可以被空格拆分为一个或多个在字典中出现的单词。

**说明**：
- 字典中的单词可以重复使用
- 不要求字典中的单词全部使用

**示例**：
- `s = "leetcode"`, `wordDict = ["leet", "code"]` → 输出 `true`
  - 因为 `"leetcode"` 可以拆分为 `"leet" + "code"`
- `s = "applepenapple"`, `wordDict = ["apple", "pen"]` → 输出 `true`
  - `"apple" + "pen" + "apple"`（注意字典单词可以重复使用）
- `s = "catsandog"`, `wordDict = ["cats", "dog", "sand", "and", "cat"]` → 输出 `false`
  - 无法找到一种拆分方式使所有子串都在字典中

---

### 解题思路

**核心洞察**：这道题的状态定义不再是「数值最大/最小」，而是「能否到达」——典型的布尔型DP。

**状态定义**：
- `dp[i]`：表示字符串 `s` 的前 `i` 个字符（即 `s[0:i]`）是否可以被字典中的单词拼接而成
- `dp[0] = true`（空字符串总是可以被拆分，作为递推起点）

**状态转移方程**：
```
对于每个位置 i（1 ≤ i ≤ len(s)）：
    dp[i] = true  如果存在 j < i，使得：
            dp[j] == true  且  s[j:i] 在 wordDict 中
```

**本质**：如果前 `j` 个字符可以被拆分，且从 `j` 到 `i` 的子串正好是一个单词，那么前 `i` 个字符也可以被拆分。

**记忆口诀**：逐个位置检查，前面能拆且后面是单词，当前就能拆。

---

### 代码实现

#### 基础DP版本（面试推荐）

```python
def wordBreak(s: str, wordDict: list[str]) -> bool:
    n = len(s)
    # dp[i] 表示 s[0:i] 能否被拆分
    dp = [False] * (n + 1)
    dp[0] = True  # 空字符串可以被拆分
    
    # 将字典转为集合，O(1) 查询
    word_set = set(wordDict)
    
    for i in range(1, n + 1):
        for j in range(i):
            # 如果前j个字符可以拆分，且s[j:i]在字典中
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break  # 找到一个即可，无需继续检查
    
    return dp[n]
```

#### 优化版本（减少内层循环次数）

```python
def wordBreakOptimized(s: str, wordDict: list[str]) -> bool:
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True
    word_set = set(wordDict)
    
    # 预先计算字典中最长单词长度，减少不必要的内层循环
    max_len = max(len(word) for word in wordDict)
    
    for i in range(1, n + 1):
        # 只需要检查最近 max_len 个位置
        for j in range(max(0, i - max_len), i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break
    
    return dp[n]
```

> 优化思路：如果字典中最长单词只有 10 个字符，那么检查 `j` 的时候只需要往前看 10 个位置就够了，没必要从 0 开始遍历。

### 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| **时间** | O(n × m × L) | n=字符串长度，m=字典单词数，L=平均单词长度。优化后可以降到 O(n × max_word_len) |
| **空间** | O(n) | dp数组长度 n+1，外加字典集合 |

---

### 经典变体

| 变体 | 核心变化 | 解法思路 |
|------|---------|---------|
| **单词拆分 II（输出所有方案）** | 不只要判断能否拆分，还要输出所有可能的拆分方式 | DFS + 记忆化搜索，或者用 DP 预处理可行性 + 回溯构造方案 |
| **单词拆分（带最少切分数）** | 求最少切几刀 | `dp[i] = min(dp[j] + 1)`，在布尔基础上增加计数维度 |
| **单词拆分（多字符串批量查询）** | 查询很多个字符串 | 用 Trie 树优化前缀匹配，或者把字典建成 AC 自动机 |
| **带权单词拆分** | 每个单词有权重，求最大/最小权重拆分 | `dp[i] = max/min(dp[j] + weight(s[j:i]))`，标准加权 DP |

## 面试技巧

### 1. 如何向面试官解释思路

**开场白**：
> "这道题是经典的字符串DP。我们定义 `dp[i]` 表示前 `i` 个字符能不能被拆分。关键观察是：如果前 `j` 个字符能拆，且 `j` 到 `i` 的子串正好是个单词，那前 `i` 个就能拆。"

**画个图现场推演**（拿 `s = "leetcode"`, `wordDict = ["leet", "code"]`）：

```
索引:    0    1    2    3    4    5    6    7    8
字符:         l    e    e    t    c    o    d    e

i=4: 检查 s[0:4]="leet" → 在字典中 ✓  → dp[4]=True
i=8: 检查 j=4: dp[4]=True 且 s[4:8]="code" → 在字典中 ✓ → dp[8]=True
```

**三句话讲清**：
1. `dp[i]` = 前 `i` 个字符能不能被字典单词拼出来
2. 枚举一个分割点 `j`，如果前 `j` 个能拼且 `j` 到 `i` 是单词，那 `i` 就能拼
3. 答案是 `dp[n]`，即整个字符串能不能被拼出来

### 2. 常见追问及应对

| 追问 | 应对策略 |
|------|----------|
| "时间复杂度能优化吗？" | 答：可以。先算字典中最长单词长度 `max_len`，内层循环只需要往前看 `max_len` 个位置，复杂度从 O(n²) 降到 O(n × max_len) |
| "字典很大怎么办？" | 答：用 Trie 树或哈希集合。如果追求极致速度，可以把字典预处理成 Trie，配合 DP 做前缀匹配 |
| "如果要输出所有拆分方案呢？" | 答：先用 DP 预处理每个位置是否可达，然后用 DFS + 记忆化回溯，只走可达的路径 |
| "如果要求最少切几刀？" | 答：把布尔型 DP 改成计数型：`dp[i] = min(dp[j] + 1 for all valid j)`，初始化 `dp[0]=0` |
| "字典里有重复单词？" | 答：不影响，转成集合自动去重 |
| "字符串超长（10⁵级别）呢？" | 答：如果 max_len 很小，O(n × max_len) 可接受。否则考虑 Trie + DP 的剪枝优化 |

### 4. 易错点提醒

⚠️ **下标越界**：`dp` 数组长度是 `n+1`，`dp[i]` 对应 `s[0:i]`（前 `i` 个字符），不是 `s[i]`
⚠️ **dp[0] 的初始化**：空字符串必须设为 `True`，否则递推无法启动
⚠️ **子串切片**：Python 中 `s[j:i]` 是左闭右开，确保理解正确
⚠️ **内层循环 break**：一旦找到一个合法的 `j` 就可以 break，不需要检查所有情况
⚠️ **忘记转集合**：如果用列表判断 `in`，时间复杂度是 O(m)，会超时
